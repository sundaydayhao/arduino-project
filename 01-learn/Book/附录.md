## 附录 A：Arduino 常用函数速查表

### A.1 数字 I/O

| 函数 | 说明 | 示例 |
|------|------|------|
| `pinMode(pin, mode)` | 设置引脚模式 | `pinMode(13, OUTPUT)` |
| `digitalWrite(pin, val)` | 数字输出 | `digitalWrite(13, HIGH)` |
| `digitalRead(pin)` | 数字输入 | `int v = digitalRead(2)` |

**mode 参数：**
- `INPUT` — 输入模式（高阻抗）
- `OUTPUT` — 输出模式
- `INPUT_PULLUP` — 输入模式（内部上拉，推荐）

### A.2 模拟 I/O

| 函数 | 说明 | 返回值 |
|------|------|--------|
| `analogRead(pin)` | 读取模拟值 | 0~1023 |
| `analogWrite(pin, val)` | PWM 输出 | — |
| `analogReference(type)` | 设置参考电压 | — |

**PWM 引脚（UNO）：** D3、D5、D6、D9、D10、D11  
**analogWrite 范围：** 0（0%占空比）~ 255（100%占空比）

### A.3 时间函数

| 函数 | 说明 | 单位 |
|------|------|------|
| `delay(ms)` | 阻塞延时 | 毫秒 |

## 附录 D：故障排查指南

### D.1 上传失败

| 错误信息 | 可能原因 | 解决方案 |
|---------|---------|---------|
| `avrdude: stk500_recv()` | 端口选择错误 | 检查工具→端口 |
| `avrdude: stk500_getsync()` | 开发板选择错误 | 检查工具→开发板 |
| `Serial port busy` | 串口被占用 | 关闭串口监视器 |
| `No device found` | 驱动未安装 | 安装 CH340/CP2102 驱动 |
| 上传时 D0/D1 有设备 | 串口冲突 | 上传时断开 D0/D1 连接 |

### D.2 程序运行异常

| 现象 | 可能原因 | 解决方案 |
|------|---------|---------|
| 程序卡死不动 | `delay()` 过长或死循环 | 检查循环逻辑，使用 `millis()` |
| 传感器读数异常 | 接线错误/电源不足 | 检查接线，测量电压 |
| LED 不亮 | 极性接反/电阻过大 | 检查正负极，换小电阻 |
| 串口乱码 | 波特率不匹配 | 统一设置波特率 |
| 复位/重启 | 电源不足 | 使用外部电源，减少负载 |
| I2C 无响应 | 地址错误/接线错误 | 运行 I2C 扫描，检查 SDA/SCL |

### D.3 常见错误信息

```
错误：'xxx' was not declared in this scope
原因：变量/函数未声明，或库未包含
解决：检查拼写，添加 #include 语句

错误：expected ';' before '}'
原因：语法错误，缺少分号
解决：检查错误行附近的语法

错误：'xxx' does not name a type
原因：类型未定义，可能缺少库
解决：添加对应的 #include

错误：sketch too big
原因：程序超过 Flash 大小（32KB）
解决：优化代码，删除不用的库

错误：not enough memory
原因：SRAM 不足（2KB）
解决：减少全局变量，使用 F() 宏
```

### D.4 硬件调试技巧

```cpp
// 技巧1：LED 指示调试
void debugBlink(int times) {
  for (int i = 0; i < times; i++) {
    digitalWrite(13, HIGH); delay(200);
    digitalWrite(13, LOW);  delay(200);
  }
}

// 技巧2：串口打印调试信息
#define DEBUG 1  // 0=关闭调试，1=开启调试
#if DEBUG
  #define DBG(x) Serial.println(x)
#else
  #define DBG(x)
#endif

// 技巧3：检查内存使用
int freeRam() {
  extern int __heap_start, *__brkval;
  int v;
  return (int)&v - (__brkval == 0 ? (int)&__heap_start : (int)__brkval);
}
// 使用：Serial.print("Free RAM: "); Serial.println(freeRam());
```

### E.1 常用电阻值速查

| 颜色环 | 数值 | 常用场景 |
|--------|------|---------|
| 红红棕金 | 220Ω | LED 限流（5V） |
| 棕黑红金 | 1kΩ | 通用限流 |
| 红红红金 | 2.2kΩ | 分压电路 |
| 棕黑橙金 | 10kΩ | 上拉/下拉电阻 |
| 棕绿橙金 | 15kΩ | 分压电路 |

**LED 限流电阻计算：**
```
R = (Vcc - Vf) / If
其中：
  Vcc = 电源电压（5V）
  Vf  = LED 正向电压（红/黄 ≈ 2V，绿/蓝 ≈ 3.2V）
  If  = LED 工作电流（通常 10~20mA）

例：5V 红色 LED，If=15mA
R = (5 - 2) / 0.015 = 200Ω → 选 220Ω
```

## 附录 H：思考题参考答案

### 第一章
1. Arduino UNO 有 **6 个** PWM 引脚：D3、D5、D6、D9、D10、D11
2. `setup()` 只执行一次（初始化），`loop()` 无限循环执行（主程序）
3. `delay(500)` — 每 0.5 秒闪烁一次，需要亮 500ms + 灭 500ms

### 第二章
1. 按键消抖是因为机械触点在接触瞬间会产生多次弹跳，消抖时间通常 **20~50ms**
2. `analogWrite()` 参数范围 **0~255**，对应占空比 0%~100%
3. ISR 中不能用 `delay()` 是因为 `delay()` 依赖定时器中断，而中断执行时其他中断被屏蔽
4. 用 `millis()` 记录上次执行时间，每次循环检查时间差是否超过间隔

### 第三章
1. 超声波最小距离 2cm 是因为发射脉冲结束前回波已到达，无法区分
2. DHT11 采样间隔 2 秒是传感器内部处理时间限制
3. PIR 需要 30 秒稳定是因为传感器需要建立热平衡基准
4. 移动平均：维护一个数组，每次用新值替换最旧值，返回平均值
