# RGB LED 控制实验

## 实验简介
学习 RGB LED 的混色原理，通过 PWM 控制三个颜色通道，实现丰富的颜色效果。

## RGB 混色原理

```
红(R) + 绿(G) = 黄色
红(R) + 蓝(B) = 品红
绿(G) + 蓝(B) = 青色
红(R) + 绿(G) + 蓝(B) = 白色
```

## 硬件清单
| 元件 | 数量 |
|------|------|
| Arduino UNO | 1 |
| RGB LED（共阴极） | 1 |
| 220Ω 电阻 | 3 |
| 面包板 | 1 |
| 杜邦线 | 若干 |

## 共阴极 vs 共阳极

| 类型 | 公共端 | 控制方式 |
|------|--------|----------|
| 共阴极 | 接 GND | HIGH = 亮 |
| 共阳极 | 接 VCC | LOW = 亮（逻辑反转） |

## 接线图

```
Arduino D9  ──── 220Ω ──── R
Arduino D10 ──── 220Ω ──── G  ──── 公共阴极 ──── GND
Arduino D11 ──── 220Ω ──── B
```
