# PWM 调光实验

## 实验简介
学习 PWM（脉冲宽度调制）技术，通过改变占空比来控制 LED 亮度。

## PWM 原理

```
占空比 25%:  ‾‾|___|‾‾|___|‾‾|___  → 较暗
占空比 50%:  ‾‾‾|___|‾‾‾|___|‾‾‾  → 中等
占空比 75%:  ‾‾‾‾‾|_|‾‾‾‾‾|_|‾‾‾  → 较亮
占空比 100%: ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾  → 最亮
```

## Arduino UNO PWM 引脚
引脚 **3, 5, 6, 9, 10, 11** 支持 PWM（在板子上标有 `~` 符号）

## 实验文件
1. `PWM调光.ino` - 自动渐亮渐灭 + 呼吸灯效果
2. `电位器调光.ino` - 用电位器手动控制亮度

## 重要函数说明

```cpp
analogWrite(pin, value);  // PWM 输出，value: 0(关) ~ 255(全亮)
analogRead(pin);          // 读取模拟值，返回 0~1023
map(value, fromLow, fromHigh, toLow, toHigh);  // 数值映射
```
