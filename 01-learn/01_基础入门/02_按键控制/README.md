# 按键控制实验

## 实验简介
学习如何读取数字输入信号，使用按键控制 LED，并掌握软件消抖技术。

## 硬件清单
| 元件 | 数量 |
|------|------|
| Arduino UNO | 1 |
| 按键开关 | 1~3 |
| LED | 1~3 |
| 220Ω 电阻 | 1~3 |
| 面包板 | 1 |
| 杜邦线 | 若干 |

## 接线图

```
Arduino D2 ──── 按键 ──── GND
Arduino D13 ──── 220Ω ──── LED(+) ──── LED(-) ──── GND
```

> 使用 INPUT_PULLUP 时，不需要外部上拉电阻！

## 为什么需要消抖？

机械按键在按下/松开时，由于弹片振动会产生多次电平跳变（抖动），
持续时间约 5~20ms。消抖就是过滤掉这些抖动，只识别一次有效按键。
