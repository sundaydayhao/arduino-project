# 土壤湿度传感器实验

## 模块简介
电阻式土壤湿度传感器通过测量土壤电阻来判断湿度，土壤越湿导电性越好，电阻越小。

## 引脚说明
| 引脚 | 说明 |
|------|------|
| VCC | 3.3V 或 5V |
| GND | 地 |
| DO | 数字输出（低于阈值输出 HIGH） |
| AO | 模拟输出（0=最湿，1023=最干） |

## 注意事项
⚠️ **长期通电会导致探针电解腐蚀！**

解决方案：只在测量时通电
```cpp
// 用数字引脚控制传感器电源
const int SENSOR_VCC = 7;
pinMode(SENSOR_VCC, OUTPUT);

// 测量时
digitalWrite(SENSOR_VCC, HIGH);
delay(100);  // 等待稳定
int value = analogRead(SOIL_AO);
digitalWrite(SENSOR_VCC, LOW);  // 测完立即断电
```
