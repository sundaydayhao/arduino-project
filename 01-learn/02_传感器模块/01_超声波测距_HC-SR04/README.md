# HC-SR04 超声波测距

## 模块简介
HC-SR04 是最常用的超声波测距模块，通过发射和接收超声波来测量距离。

## 规格参数
| 参数 | 值 |
|------|-----|
| 工作电压 | 5V DC |
| 静态电流 | < 2mA |
| 工作电流 | 15mA |
| 测量角度 | 15° |
| 测量范围 | 2cm ~ 400cm |
| 精度 | ±3mm |
| 触发信号 | 10μs TTL 脉冲 |

## 引脚说明
| 引脚 | 说明 |
|------|------|
| VCC | 5V 电源 |
| Trig | 触发输入（发送超声波） |
| Echo | 回波输出（接收超声波） |
| GND | 地 |

## 工作原理

```
Arduino          HC-SR04
   │                │
   │── Trig 10μs ──>│
   │                │── 发射 8个40kHz超声波 ──>
   │                │                         │
   │                │<── 接收回波 ─────────────┘
   │<── Echo 高电平 ─│
   │                │
距离 = Echo高电平时间 × 340m/s ÷ 2
```

## 实验文件
1. `超声波测距.ino` - 基础测距
2. `超声波距离报警.ino` - 距离报警系统
