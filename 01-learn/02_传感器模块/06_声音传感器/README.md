# 声音传感器实验

## 模块简介
声音传感器模块包含麦克风和比较器，可以检测环境声音并输出数字或模拟信号。

## 引脚说明
| 引脚 | 说明 |
|------|------|
| VCC | 3.3V 或 5V |
| GND | 地 |
| DO | 数字输出（超过阈值输出 HIGH） |
| AO | 模拟输出（声音强度 0~1023） |

## 灵敏度调节
模块上的蓝色旋钮（电位器）用于调节触发阈值：
- 顺时针旋转 → 灵敏度降低（需要更大声音才触发）
- 逆时针旋转 → 灵敏度提高（较小声音即可触发）

## 实验文件
1. `声音传感器.ino` - 声控灯 + 串口波形显示

## 串口绘图仪使用
1. 上传代码后，打开 `工具 → 串口绘图仪`
2. 可以看到声音波形的实时显示
