# 光敏电阻（LDR）实验

## 模块简介
光敏电阻（Light Dependent Resistor，LDR）是一种光控电阻，光照越强阻值越小。

## 特性曲线

```
阻值(kΩ)
  100 |*
   50 | *
   20 |  *
   10 |   *
    5 |    **
    1 |      ***
      +----------→ 光照强度(lux)
     暗          亮
```

## 硬件连接（分压电路）

```
5V ──── 10kΩ ──┬──── A0（读取电压）
               │
              LDR（光照强→阻值小→电压低）
               │
GND ───────────┘
```

## 实验文件
1. `光敏电阻.ino` - 读取光照值，自动调节 LED 亮度
2. `自动夜灯.ino` - 天黑自动开灯系统

## 迟滞控制原理

防止在阈值附近频繁切换：

```
开灯阈值: 600
关灯阈值: 400

光照值 > 600 → 开灯
光照值 < 400 → 关灯
400~600 之间 → 保持当前状态
```
