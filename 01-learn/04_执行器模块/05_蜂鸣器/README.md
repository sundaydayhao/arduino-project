# 蜂鸣器实验

## 模块简介
蜂鸣器是一种发声元件，分为有源蜂鸣器和无源蜂鸣器两种。

## 有源 vs 无源蜂鸣器

| 特性 | 有源蜂鸣器 | 无源蜂鸣器 |
|------|-----------|-----------|
| 内部结构 | 含振荡电路 | 仅压电片 |
| 驱动方式 | 直流电压 | PWM 方波 |
| 音调 | 固定 | 可变 |
| 使用难度 | 简单 | 稍复杂 |
| 识别方法 | 底部有绿色电路板 | 底部无电路板 |

## 音符频率对照表

| 音符 | 频率(Hz) | 音符 | 频率(Hz) |

| C4（中央C） | 262 | C5 | 523 |

## 硬件连接

```
蜂鸣器（+）→ D8
蜂鸣器（-）→ GND
```

## 重要函数

```cpp
tone(pin, frequency);           // 持续发声
tone(pin, frequency, duration); // 发声指定时间（ms）
noTone(pin);                    // 停止发声
```
