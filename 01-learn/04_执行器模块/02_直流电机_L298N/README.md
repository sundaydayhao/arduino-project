# L298N 直流电机控制实验

## 模块简介
L298N 是一款双 H 桥电机驱动芯片，可同时驱动两个直流电机，支持正反转和 PWM 调速。

## 规格参数
| 参数 | 值 |
|------|-----|
| 工作电压 | 5~35V |
| 最大电流 | 2A（每通道） |
| 逻辑电压 | 5V |
| 控制方式 | IN1/IN2/IN3/IN4 + ENA/ENB |

## H 桥工作原理

```
     VCC
      │
   ┌──┴──┐
  Q1    Q2
   │    │
OUT+    OUT-  ← 电机
   │    │
  Q3    Q4
   └──┬──┘
      │
     GND

IN1=H, IN2=L → 正转
IN1=L, IN2=H → 反转
IN1=L, IN2=L → 停止（自由滑行）
IN1=H, IN2=H → 刹车
```

## 硬件连接

```
L298N          Arduino
IN1 ─────────── D8
IN2 ─────────── D9（PWM）
IN3 ─────────── D10（PWM）
IN4 ─────────── D11
ENA ─────────── D9（或跳线帽短接=全速）
ENB ─────────── D10（或跳线帽短接=全速）
VCC ─────────── 外部电源（6~12V）
GND ─────────── 外部GND + Arduino GND（共地！）
5V  ─────────── Arduino 5V（可选）
```

## 实验文件
1. `L298N电机控制.ino` - 单电机控制（正反转、调速）
2. `小车控制.ino` - 双轮小车串口控制

## 注意事项
- ⚠️ 必须使用**外部电源**驱动电机
- ⚠️ 外部电源 GND 必须与 Arduino GND **共地**
- ⚠️ 电机启动时电流大，可能导致 Arduino 复位（需外部供电）
