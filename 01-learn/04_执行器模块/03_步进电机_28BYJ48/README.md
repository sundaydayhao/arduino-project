# 28BYJ-48 步进电机实验

## 模块简介
28BYJ-48 是一款常用的小型步进电机，配合 ULN2003 驱动板使用，适合精确位置控制。

## 规格参数
| 参数 | 值 |
|------|-----|
| 工作电压 | 5V DC |
| 步距角 | 5.625°（减速前） |
| 减速比 | 1:64 |
| 每圈步数 | 2048（半步模式） |
| 相数 | 4相 |
| 驱动方式 | 单极性 |

## 步进电机工作原理

```
4相步进电机励磁顺序（全步模式）：
步骤  IN1  IN2  IN3  IN4
  1    H    L    L    L
  2    L    H    L    L
  3    L    L    H    L
  4    L    L    L    H
  1    H    L    L    L  ← 循环
```

## 硬件连接

```
ULN2003 板    Arduino
   IN1 ──────── D8
   IN2 ──────── D9
   IN3 ──────── D10
   IN4 ──────── D11
   VCC ──────── 5V（建议外部供电）
   GND ──────── GND
```

## 步进电机 vs 直流电机 vs 舵机

| 特性 | 步进电机 | 直流电机 | 舵机 |
|------|----------|----------|------|
| 位置精度 | 高 | 低 | 中 |
| 速度 | 慢 | 快 | 中 |
| 扭矩 | 中 | 高 | 中 |
| 控制复杂度 | 中 | 低 | 低 |
| 应用 | 3D打印机、CNC | 小车、风扇 | 机械臂、舵面 |
