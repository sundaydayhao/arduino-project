# 8×8 点阵 LED（MAX7219）实验

## 模块简介
MAX7219 是一款串行接口 LED 显示驱动芯片，可驱动 8×8 点阵 LED 或 8 位 7 段数码管。

## 规格参数
| 参数 | 值 |
|------|-----|
| 点阵大小 | 8×8 = 64 个 LED |
| 接口 | SPI（3线） |
| 工作电压 | 5V |
| 亮度控制 | 16级（软件控制） |
| 级联数量 | 最多 8 个模块 |

## 硬件连接

```
MAX7219 模块    Arduino UNO
   VCC ──────── 5V
   GND ──────── GND
   DIN ──────── D11（MOSI）
   CS  ──────── D10
   CLK ──────── D13（SCK）
```

## 需要安装的库
- **MD_MAX72XX**：`工具 → 管理库 → 搜索 MD_MAX72XX`
- **SPI**（Arduino 内置）

## 点阵图案设计

每行用一个字节（8位）表示，1=亮，0=灭：
```
心形图案：
0b00000000  →  ........
0b01100110  →  .##..##.
0b11111111  →  ########
0b11111111  →  ########
0b01111110  →  .######.
0b00111100  →  ..####..
0b00011000  →  ...##...
0b00000000  →  ........
```
