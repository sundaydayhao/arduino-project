# LCD1602 显示屏实验

## 模块简介
LCD1602 是一款 16 列 2 行的字符型液晶显示屏，通过 I2C 转接板可以只用 2 根线控制。

## 规格参数
| 参数 | 值 |
|------|-----|
| 显示内容 | 16列 × 2行 字符 |
| 字符大小 | 5×8 点阵 |
| 工作电压 | 5V |
| I2C 地址 | 0x27 或 0x3F |
| 背光 | 可控制开关 |

## 硬件连接（I2C 接口）

```
LCD1602 I2C    Arduino UNO
   VCC ──────── 5V
   GND ──────── GND
   SDA ──────── A4
   SCL ──────── A5
```

## 需要安装的库
- **LiquidCrystal_I2C**：`工具 → 管理库 → 搜索 LiquidCrystal I2C`

## 常用函数

```cpp
lcd.init();              // 初始化
lcd.backlight();         // 开背光
lcd.noBacklight();       // 关背光
lcd.clear();             // 清屏
lcd.setCursor(col, row); // 设置光标位置（从0开始）
lcd.print("text");       // 显示文字
lcd.write(charIndex);    // 显示自定义字符
lcd.createChar(n, data); // 创建自定义字符（n: 0~7）
```

## 自定义字符设计
每个字符是 5×8 点阵，用二进制表示：
```
0b01110,  // .###.
0b10001,  // #...#
0b10001,  // #...#
0b11111,  // #####
0b10001,  // #...#
0b10001,  // #...#
0b10001,  // #...#
0b00000   // .....
```
