# 线性回归预测

> 在 Arduino 上实现在线线性回归，对传感器数据进行趋势预测。

## 📖 学习目标

- 理解线性回归的基本原理
- 掌握在资源受限的微控制器上实现 ML 算法的方法
- 学会用历史数据预测未来趋势

## 🧠 算法原理

**线性回归**是最基础的机器学习算法，用于找到数据的线性关系：

```
y = w * x + b
```

其中：
- `x` 是输入特征（如时间）
- `y` 是预测值（如温度）
- `w` 是权重（斜率）
- `b` 是偏置（截距）

### 在线学习（Online Learning）

由于 Arduino 内存有限，无法存储大量历史数据，我们使用**在线学习**方式：
每来一个新数据点，就更新模型参数，无需存储所有历史数据。

使用**增量最小二乘法**（Incremental Least Squares）：

```
n    = 样本数量
Sx   = Σx
Sy   = Σy
Sxx  = Σ(x²)
Sxy  = Σ(x*y)

w = (n*Sxy - Sx*Sy) / (n*Sxx - Sx*Sx)
b = (Sy - w*Sx) / n
```
