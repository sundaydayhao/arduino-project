# K 近邻分类器（KNN）

> 在 Arduino 上实现 K 近邻算法，对传感器数据进行多类别分类。

## 📖 学习目标

- 理解 KNN 算法的工作原理
- 掌握特征归一化的重要性
- 学会在嵌入式系统上实现分类器

## 🧠 算法原理

**K 近邻（K-Nearest Neighbors）** 是一种基于实例的学习算法：

1. 存储训练样本（特征 + 标签）
2. 对新样本，计算它与所有训练样本的距离
3. 找到距离最近的 K 个样本
4. 用这 K 个样本中出现最多的类别作为预测结果

### 距离计算（欧氏距离）

```
d = sqrt((x1-x2)² + (y1-y2)² + ...)
```

### 特征归一化

不同特征的量纲不同（如温度 0~50°C，湿度 0~100%），需要归一化到 [0,1]：

```
x_norm = (x - x_min) / (x_max - x_min)
```

## 🔧 硬件需求

| 组件 | 数量 | 说明 |

```
DHT11 DATA    → D2

```

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `KNN分类器.ino` | KNN 分类器，识别环境状态（舒适/炎热/潮湿/干燥） |

## 🏷️ 分类标签

本示例将环境状态分为 4 类：

| 类别 | 温度 | 湿度 | 光照 |
|------|------|------|------|
| 舒适 | 20~26°C | 40~60% | 任意 |
| 炎热 | >28°C | 任意 | 任意 |
| 潮湿 | 任意 | >70% | 任意 |
| 干燥 | 任意 | <30% | 任意 |

## 💡 应用场景

- 环境状态分类（舒适/炎热/潮湿）
- 土壤状态识别（干燥/适中/湿润）
- 手势识别（配合 IMU 传感器）
- 故障诊断（正常/异常分类）
