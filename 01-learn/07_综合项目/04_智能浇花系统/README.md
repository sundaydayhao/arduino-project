# 综合项目：智能浇花系统

## 项目简介
自动监测土壤湿度，在植物缺水时自动启动水泵浇水，并显示环境数据。

## 功能特性
- 💧 土壤湿度自动检测
- 🚿 低于阈值自动浇水
- 🌡️ 温湿度环境监测
- 📺 LCD 实时显示状态
- 📊 串口记录浇水日志

## 硬件清单
| 元件 | 数量 |
|------|------|
| Arduino UNO | 1 |
| 土壤湿度传感器 | 1 |
| DHT11 | 1 |
| 5V 继电器模块 | 1 |
| 小型水泵（5V） | 1 |
| 硅胶管 | 适量 |
| LCD1602 I2C | 1 |

## 注意事项
- ⚠️ 水泵和电路要做好防水处理
- ⚠️ 土壤湿度传感器不要长期通电（会腐蚀）
- 建议使用外部 5V 电源驱动水泵

## 扩展思路
- 加入 RTC 实现定时浇水
