# 综合项目：温度报警器

## 项目简介
实时监测环境温湿度，超过设定阈值时触发声光报警。

## 功能特性
- 🌡️ DHT11 实时温湿度监测
- 📺 LCD1602 显示数据
- 🔔 超阈值声光报警
- 📊 串口数据记录

## 硬件清单
| 元件 | 数量 |
|------|------|
| Arduino UNO | 1 |
| DHT11 | 1 |
| LCD1602 I2C | 1 |
| 蜂鸣器 | 1 |
| 红色 LED | 1 |
| 绿色 LED | 1 |
| 220Ω 电阻 | 2 |

## 报警阈值（可在代码中修改）
- 高温报警：> 30°C
- 低温报警：< 10°C
- 高湿报警：> 80%RH

## 扩展思路
- 加入蓝牙，手机接收报警通知
- 加入 SD 卡记录温度历史曲线
- 加入继电器控制空调/加热器
