# 综合项目：RFID 门禁系统

## 项目简介
基于 RFID 刷卡验证，舵机控制门锁，LCD 显示状态的完整门禁系统。

## 功能特性
- 🔑 RFID 刷卡验证身份
- 🚪 舵机模拟门锁开关
- 📺 LCD 显示状态
- 🔔 蜂鸣器提示音
- 👑 管理员卡添加新卡

## 硬件清单
| 元件 | 数量 |
|------|------|
| Arduino UNO | 1 |
| RC522 RFID 模块 | 1 |
| RFID 卡/钥匙扣 | 若干 |
| SG90 舵机 | 1 |
| LCD1602 I2C | 1 |
| 蜂鸣器 | 1 |
| 红/绿 LED | 各1 |

## 使用说明
1. 修改代码中的 `adminUID` 为你的管理员卡 UID
2. 上传代码，打开串口监视器
3. 刷管理员卡进入添加模式
4. 刷新卡片完成授权
5. 再次刷管理员卡退出添加模式
