# AI 智能环境监测系统

> 综合运用机器学习算法，构建一个能够自主学习、预测和异常检测的智能环境监测系统。

## 📖 项目概述

本项目将前面学到的 AI/ML 算法整合到一个完整的系统中：

| 功能 | 算法 | 说明 |
|------|------|------|
| 环境状态分类 | KNN | 识别当前环境状态 |
| 温度趋势预测 | 线性回归 | 预测未来温度变化 |
| 异常值检测 | Z-Score + EWMA | 检测传感器异常 |
| 自适应阈值 | 移动平均 | 动态调整报警阈值 |

## 🎯 功能需求

1. 🌡️ **多传感器采集**：温度、湿度、光照实时监测
2. 🤖 **AI 状态分类**：KNN 自动识别环境状态（舒适/炎热/潮湿/干燥）
3. 📈 **趋势预测**：线性回归预测未来 10 分钟温度
4. 🚨 **智能报警**：异常检测 + 自适应阈值，减少误报
5. 📺 **OLED 显示**：实时显示传感器数据和 AI 分析结果
6. 💾 **数据记录**：串口输出 CSV 格式数据，便于 PC 端分析

## 🔧 硬件需求

| 组件 | 数量 | 说明 |
|------|------|------|
| Arduino UNO/Nano | 1 | 主控板 |
| DHT11 温湿度传感器 | 1 | 温湿度采集 |
| 光敏电阻 + 10kΩ | 1 | 光照采集 |
| OLED SSD1306 (I2C) | 1 | 状态显示 |
| 蜂鸣器 | 1 | 异常报警 |
| 红色 LED | 1 | 报警指示 |
| 绿色 LED | 1 | 正常指示 |
| 220Ω 电阻 | 2 | LED 限流 |

## 📌 硬件连接

```
DHT11 DATA    → D2
光敏电阻分压  → A0
OLED SDA      → A4
OLED SCL      → A5
蜂鸣器        → D8
红色 LED      → D12（220Ω）
绿色 LED      → D13（220Ω）
```

## 📊 串口输出格式

系统每 10 秒输出一行 CSV 数据：

```
时间戳(ms),温度(°C),湿度(%),光照,状态,温度Z分数,预测温度(+10min),异常标志
```

可用 Arduino IDE 串口绘图仪或 Python 脚本实时可视化。

## 🔄 系统状态机

```
初始化
  ↓
预热阶段（收集30个样本建立基线）
  ↓
正常运行
  ├── 每5秒：读取传感器 → KNN分类 → 异常检测 → 更新显示
  ├── 每10秒：线性回归更新 → 趋势预测
  └── 异常时：触发报警 → 记录事件
```
