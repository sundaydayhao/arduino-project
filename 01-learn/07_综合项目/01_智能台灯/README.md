# 综合项目：智能台灯

## 项目简介
结合光敏传感器、PIR人体感应、按键、电位器，实现一个功能完整的智能台灯。

## 功能特性
- 🌙 **光控**：环境暗时才允许开灯
- 👤 **人感**：检测到人自动开灯，无人30秒后自动关灯
- 🔘 **手动**：按键切换手动/自动模式
- 🔆 **调光**：电位器调节亮度
- 📊 **监控**：串口实时显示状态

## 硬件清单
| 元件 | 数量 |
|------|------|
| Arduino UNO | 1 |
| 光敏电阻 + 10kΩ | 1 |
| PIR 传感器 | 1 |
| 按键 | 1 |
| 电位器 10kΩ | 1 |
| LED（或继电器+灯泡） | 1 |
| 220Ω 电阻 | 1 |

## 接线图
```
LDR分压 → A0
PIR OUT → D2
按键    → D3（内部上拉）
电位器  → A1
LED     → D9（PWM）
```

## 扩展思路
- 加入 LCD 显示当前状态
- 加入 RTC 实现定时开关
- 加入蓝牙实现手机控制
- 用继电器控制真实灯泡
