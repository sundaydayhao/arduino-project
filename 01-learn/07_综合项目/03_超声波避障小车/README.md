# 综合项目：超声波避障小车

## 项目简介
使用超声波传感器检测障碍物，配合舵机扫描，实现自动避障行驶。

## 功能特性
- 🚗 自动前进
- 🔍 超声波检测障碍物（< 20cm 停车）
- 🔄 舵机左右扫描，选择最优方向
- 📡 串口输出距离信息

## 硬件清单
| 元件 | 数量 |
|------|------|
| Arduino UNO | 1 |
| HC-SR04 超声波 | 1 |
| SG90 舵机 | 1 |
| L298N 电机驱动 | 1 |
| TT 直流电机 | 2 |
| 小车底盘 | 1 |
| 7.4V 锂电池 | 1 |

## 避障算法
```
检测前方距离
├── 距离 > 20cm → 前进
└── 距离 ≤ 20cm → 停车
    ├── 扫描左方距离
    ├── 扫描右方距离
    └── 转向较宽敞一侧
```
