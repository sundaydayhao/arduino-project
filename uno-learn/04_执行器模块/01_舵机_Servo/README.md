# 舵机控制实验

## 模块简介
舵机（Servo）是一种位置控制电机，通过 PWM 信号控制输出轴的角度。

## 常见舵机规格

| 型号 | 角度 | 扭矩 | 电压 |
|------|------|------|------|
| SG90 | 0~180° | 1.8kg·cm | 4.8~6V |
| MG996R | 0~180° | 9.4kg·cm | 4.8~7.2V |
| DS3218 | 0~270° | 20kg·cm | 6~7.4V |

## 舵机控制原理

```
PWM 信号（50Hz = 20ms 周期）：
脉宽 0.5ms → 0°
脉宽 1.5ms → 90°（中间）
脉宽 2.5ms → 180°

|‾‾|_________________|  0.5ms → 0°
|‾‾‾‾‾‾‾‾|___________|  1.5ms → 90°
|‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾|___|  2.5ms → 180°
```

## 硬件连接

```
舵机线色    Arduino
红色 ─────── 5V（建议外部供电）
棕色 ─────── GND
橙色 ─────── D9（信号）
```

## 需要安装的库
- **Servo**（Arduino 内置）

## 实验文件
1. `舵机控制.ino` - 串口控制角度 + 扫描模式
2. `电位器控制舵机.ino` - 电位器实时控制

## 注意事项
- ⚠️ 舵机启动电流大，多个舵机必须使用**外部电源**
- ⚠️ 外部电源 GND 必须与 Arduino GND **共地**
- 舵机不要强制转动超过限位，会损坏齿轮
