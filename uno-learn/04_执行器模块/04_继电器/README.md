# 继电器控制实验

## 模块简介
继电器是一种电磁开关，用小电流（Arduino 输出）控制大电流（电机、灯泡等）。

## 继电器结构

```
        线圈（控制端）
        ┌─────────┐
Arduino ─┤  电磁铁  ├─ GND
        └────┬────┘
             │ 磁力
        ┌────┴────┐
COM ────┤  触点   ├──── NO（常开）
        └─────────┘──── NC（常闭）

线圈通电 → 触点吸合 → COM 与 NO 连通
线圈断电 → 触点弹开 → COM 与 NC 连通
```

## 引脚说明
| 引脚 | 说明 |
|------|------|
| VCC | 5V |
| GND | 地 |
| IN | 控制信号（低电平或高电平触发，看模块） |
| COM | 公共端 |
| NO | 常开端（默认断开） |
| NC | 常闭端（默认闭合） |

## 安全警告
- ⚠️ 继电器可控制 **220V 交流电**，务必注意安全！
- ⚠️ 高压接线必须由**专业人员**操作
- ⚠️ 实验时建议只控制**低压设备**
