# MQ-2 气体传感器实验

## 模块简介
MQ-2 是一款半导体气体传感器，可检测多种可燃气体和烟雾。

## 可检测气体
| 气体 | 检测范围 |
|------|----------|
| 液化气（LPG） | 200~10000ppm |
| 丁烷 | 200~10000ppm |
| 甲烷 | 5000~20000ppm |
| 酒精 | 100~2000ppm |
| 烟雾 | 200~10000ppm |

## 引脚说明
| 引脚 | 说明 |
|------|------|
| VCC | 5V |
| GND | 地 |
| DO | 数字输出（超过阈值=LOW） |
| AO | 模拟输出（浓度越高值越大） |

## 注意事项
- ⚠️ 传感器上电后需要**预热 20~30 秒**才能稳定
- ⚠️ 传感器工作时**会发热**，属正常现象（约 50°C）
- ⚠️ 不要在传感器附近使用**明火**
- ⚠️ 长期使用需要定期**校准**

## MQ 系列传感器对比

| 型号 | 主要检测气体 |
|------|-------------|
| MQ-2 | 可燃气体、烟雾 |
| MQ-3 | 酒精 |
| MQ-4 | 甲烷、天然气 |
| MQ-5 | 液化气、天然气 |
| MQ-7 | 一氧化碳 |
| MQ-9 | 一氧化碳、可燃气体 |
