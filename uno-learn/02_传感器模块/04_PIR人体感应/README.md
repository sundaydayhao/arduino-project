# PIR 人体红外感应

## 模块简介
PIR（Passive Infrared）传感器通过检测人体发出的红外辐射变化来感知运动。

## 规格参数
| 参数 | 值 |
|------|-----|
| 工作电压 | 5V DC |
| 检测距离 | 3~7m（可调） |
| 检测角度 | 120° |
| 延时时间 | 3s~5min（可调） |
| 触发方式 | 可重复/单次触发 |

## 引脚说明
| 引脚 | 说明 |
|------|------|
| VCC | 5V 电源 |
| OUT | 数字输出（HIGH=检测到） |
| GND | 地 |

## 模块上的调节旋钮

```
[灵敏度旋钮]  顺时针 → 检测距离增大
[延时旋钮]    顺时针 → 触发后保持时间增长
[跳线帽]      H位置 = 重复触发模式
              L位置 = 单次触发模式
```

## 实验文件
1. `PIR人体感应.ino` - 感应灯控制

## 注意事项
- PIR 传感器上电后需要约 **30 秒**预热稳定
- 避免将传感器对准空调出风口、暖气等热源
- 菲涅尔透镜（白色半球）不要用手触摸
