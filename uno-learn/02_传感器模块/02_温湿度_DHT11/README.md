# DHT11 温湿度传感器

## 模块简介
DHT11 是一款常用的数字温湿度传感器，内置 ADC 和单总线通信接口。

## 规格对比

| 参数 | DHT11 | DHT22 |
|------|-------|-------|
| 温度范围 | 0~50°C | -40~80°C |
| 温度精度 | ±2°C | ±0.5°C |
| 湿度范围 | 20~90%RH | 0~100%RH |
| 湿度精度 | ±5%RH | ±2~5%RH |
| 采样率 | 1次/秒 | 0.5次/秒 |
| 价格 | 低 | 较高 |

## 硬件连接

```
DHT11          Arduino
VCC  ────────── 5V
DATA ──┬──────── D2
       │
      4.7kΩ（上拉电阻）
       │
VCC  ──┘
GND  ────────── GND
```

> 注意：DATA 引脚需要 4.7kΩ 上拉电阻！
> 部分模块已内置上拉电阻，可直接连接。

## 需要安装的库
1. **DHT sensor library**（Adafruit）
2. **Adafruit Unified Sensor**
3. **LiquidCrystal_I2C**（LCD 显示实验需要）

## 实验文件
1. `DHT11温湿度.ino` - 基础温湿度读取
2. `温湿度显示LCD.ino` - 配合 LCD1602 显示
