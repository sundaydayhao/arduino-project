# 雨滴传感器实验

## 模块简介
雨滴传感器通过检测水滴导电来判断是否下雨及雨量大小。

## 引脚说明
| 引脚 | 说明 |
|------|------|
| VCC | 5V |
| GND | 地 |
| DO | 数字输出（有雨=LOW，无雨=HIGH） |
| AO | 模拟输出（值越小雨量越大） |

## 雨量等级参考

| AO 值 | 雨量等级 |
|-------|----------|
| > 800 | 无雨 |
| 500~800 | 小雨 |
| 200~500 | 中雨 |
| < 200 | 大雨 |

> 以上阈值仅供参考，需根据实际传感器校准
