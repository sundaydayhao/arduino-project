# 红外遥控实验

## 模块简介
红外遥控是一种常见的无线控制方式，使用 38kHz 调制的红外光传输数据。

## 常见红外协议
| 协议 | 特点 | 常见设备 |
|------|------|----------|
| NEC | 最常用，32位 | 电视、空调遥控器 |
| Sony SIRC | 12/15/20位 | 索尼设备 |
| RC5/RC6 | 欧洲标准 | 飞利浦设备 |

## 硬件连接

```
红外接收模块（如 VS1838B）
  ┌─────────────────┐
  │  ○  ○  ○        │
  │  │  │  │        │
  OUT GND VCC       │
   │   │   │
  D11 GND  5V
```

## 需要安装的库
- **IRremote**（by shirriff）：`工具 → 管理库 → 搜索 IRremote`

## 如何获取遥控器编码

1. 上传 `红外遥控接收.ino`
2. 打开串口监视器
3. 按下遥控器各个按键
4. 记录串口输出的十六进制编码
5. 将编码填入代码中对应的常量
