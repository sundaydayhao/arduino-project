# 异常检测（Anomaly Detection）

> 在 Arduino 上实现基于统计学的异常检测，识别传感器数据中的异常值。

## 📖 学习目标

- 理解异常检测的基本原理
- 掌握 Z-Score 和移动窗口统计方法
- 学会在嵌入式系统中实现实时异常检测

## 🧠 算法原理

### 方法一：Z-Score 异常检测

Z-Score 衡量数据点偏离均值的程度（以标准差为单位）：

```
z = (x - μ) / σ

μ = 均值
σ = 标准差
```

当 `|z| > threshold`（通常取 2.0~3.0）时，认为该点是异常值。

### 方法二：移动窗口统计

使用滑动窗口维护最近 N 个样本的统计量：

```
窗口均值 = Σ(最近N个值) / N
窗口标准差 = sqrt(Σ(xi - μ)² / N)
```

### 方法三：IQR（四分位距）方法

```
Q1 = 第25百分位数
Q3 = 第75百分位数
IQR = Q3 - Q1

异常范围：x < Q1 - 1.5*IQR  或  x > Q3 + 1.5*IQR
```
