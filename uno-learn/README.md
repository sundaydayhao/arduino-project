# 🤖 Arduino 创客学习套件

> 适合科技创客、学生和爱好者的 Arduino 综合学习资料库

## 📦 套件内容概览

本套件涵盖从基础入门到综合项目的完整 Arduino 学习路径，包含以下模块：

| 模块 | 内容 |
|------|------|
| 01_基础入门 | LED、按键、PWM、模拟输入、串口通信 |
| 02_传感器模块 | 超声波、温湿度、光敏、PIR、红外、声音、土壤、雨滴、气体 |
| 03_显示模块 | LCD1602、OLED、数码管、点阵、TFT彩屏 |
| 04_执行器模块 | 舵机、直流电机、步进电机、继电器、蜂鸣器 |
| 05_通信模块 | 蓝牙HC-05、WiFi ESP8266、RFID RC522、NRF24L01 |
| 06_存储模块 | EEPROM、SD卡、RTC实时时钟 |
| 07_综合项目 | 智能台灯、温度报警器、避障小车、智能浇花、门禁系统、**AI智能环境监测** |
| 08_AI机器学习 | 线性回归预测、KNN分类器、异常检测、神经网络推理、TFLite手势识别 |

## 🛠️ 所需硬件清单

### 主控板
- Arduino UNO R3 × 1
- Arduino Nano × 1（可选）
- Arduino Mega 2560 × 1（综合项目推荐）

- 220Ω 电阻 × 20
- 10kΩ 电阻 × 10

- 按键开关 × 5
- 电位器（10kΩ）× 2
- 光敏电阻 × 2
- 蜂鸣器（有源/无源）各 × 1
- 面包板 × 2

### 传感器模块
- HC-SR04 超声波传感器 × 1
- DHT11 温湿度传感器 × 1
- DHT22 温湿度传感器 × 1（高精度）
- PIR 人体红外传感器 × 1
- 红外接收模块 + 遥控器 × 1
- 声音传感器模块 × 1
- 土壤湿度传感器 × 1
- 雨滴传感器 × 1
- MQ-2 气体传感器 × 1

### 显示模块
- LCD1602（带 I2C 转接板）× 1
- 0.96" OLED 显示屏（I2C）× 1
- 4位7段数码管 × 1
- 8×8 点阵 LED 模块 × 1

### 执行器模块
- SG90 舵机 × 2
- L298N 电机驱动模块 × 1
- 28BYJ-48 步进电机 + ULN2003 驱动板 × 1
- 5V 继电器模块 × 1

### 通信模块
- HC-05 蓝牙模块 × 1
- ESP8266 WiFi 模块（ESP-01）× 1
- RFID RC522 模块 + 卡片 × 1

### 存储模块
- SD 卡模块 × 1
- DS3231 RTC 实时时钟模块 × 1

## 📚 学习路径建议

```
第1周：基础入门（01_基础入门）
  └── LED → 按键 → PWM → 模拟输入 → 串口

第2周：传感器入门（02_传感器模块）
  └── 超声波 → 温湿度 → 光敏 → PIR

第3周：显示与输出（03_显示模块 + 04_执行器模块）
  └── LCD → OLED → 舵机 → 电机

第4周：通信与存储（05_通信模块 + 06_存储模块）
  └── 蓝牙 → WiFi → RFID → SD卡

第5-6周：综合项目（07_综合项目）
  └── 选择感兴趣的项目动手实践

第7-8周：AI 与机器学习（08_AI机器学习）
  └── 线性回归 → KNN分类 → 异常检测 → 神经网络 → TFLite
```

## 🔧 开发环境配置

1. 下载 [Arduino IDE](https://www.arduino.cc/en/software)（推荐 2.x 版本）
2. 安装必要库（见各模块 README）
3. 选择正确的开发板和端口
4. 上传代码前检查接线

## 📌 注意事项

- ⚠️ 接线前务必断开电源
- ⚠️ 注意电压匹配（5V/3.3V）
- ⚠️ 电机等大功率设备需要独立供电
- ✅ 建议使用面包板先测试，再焊接
- ✅ 遇到问题先检查接线，再检查代码
