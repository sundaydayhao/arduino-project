# 模拟输入实验

## 实验简介
学习 Arduino 的模拟输入功能，读取电位器、光敏电阻等模拟传感器的值。

## 硬件清单
| 元件 | 数量 |
|------|------|
| Arduino UNO | 1 |
| 电位器（10kΩ） | 1 |
| 光敏电阻 | 1 |
| 10kΩ 电阻 | 2 |
| 面包板 | 1 |
| 杜邦线 | 若干 |

## 分压电路原理

```
5V ──── R1(10kΩ) ──┬──── A0
                   │
              传感器/R2
                   │
GND ───────────────┘

输出电压 = 5V × R2 / (R1 + R2)
```

## 实验文件
1. `模拟输入读取.ino` - 同时读取多个模拟传感器
2. `电压表.ino` - 简易电压表（带滑动平均滤波）

## 重要函数说明

```cpp
analogRead(pin);                    // 读取模拟值，返回 0~1023
map(val, inMin, inMax, outMin, outMax);  // 数值映射
constrain(val, min, max);           // 限制数值范围
```

## Arduino UNO 模拟引脚
A0, A1, A2, A3, A4, A5（共6个）
