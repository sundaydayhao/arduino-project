## 🛠️ 所需硬件

### 核心控制板
- **Arduino UNO R3** × 1（主要使用）
- Arduino Nano × 1（可选）
- Arduino Mega 2560 × 1（综合项目推荐）

### 基础元件
| 元件 | 规格 | 数量 |
|------|------|------|
| LED | 红/绿/蓝/黄 | 各 5 个 |
| RGB LED | 共阴极 | 2 个 |
| 电阻 | 220Ω | 20 个 |
| 电阻 | 10kΩ | 10 个 |
| 按键开关 | 4 脚 | 5 个 |
| 电位器 | 10kΩ | 2 个 |
| 面包板 | 830 孔 | 2 块 |
| 杜邦线 | 公对公/公对母/母对母 | 各 40 根 |

### 传感器与模块
- HC-SR04 超声波、DHT11 温湿度、PIR 人体感应
- 光敏电阻、声音传感器、土壤湿度、雨滴传感器、MQ-2 气体传感器
- LCD1602（I2C）、OLED 0.96"、七段数码管、点阵 LED MAX7219
- SG90 舵机、L298N 电机驱动、28BYJ-48 步进电机、继电器
- HC-05 蓝牙、ESP8266 WiFi、RFID RC522
- SD 卡模块、DS3231 RTC

## 💻 开发环境

- **Arduino IDE 2.x**（推荐）：[下载地址](https://www.arduino.cc/en/software)
- **操作系统**：Windows / macOS / Linux 均支持
- **驱动**：CH340 或 CP2102 USB 转串口驱动

## 📌 使用说明

1. 按章节顺序学习，每章都有理论讲解 + 代码示例 + 接线图说明
2. 代码均来自本项目，可直接复制到 Arduino IDE 使用
3. 每个实验都有**硬件连接说明**和**注意事项**
4. 遇到问题先查阅[附录](./附录.md)的故障排查章节

---

## ⚠️ 安全须知

> - 接线前务必**断开电源**
> - 注意电压匹配（5V / 3.3V 不可混用）
> - 电机等大功率设备需要**独立供电**
> - 建议先在面包板上测试，再焊接固定
