## 2.1 实验一：LED 闪烁进阶

### 2.1.1 基础 LED 闪烁

在第一章我们已经完成了基础 LED 闪烁，本节进一步学习多频率闪烁控制。

**硬件连接：**
```
Arduino D13 ──[220Ω]── LED(+)
                        LED(-) ── GND
```

### 2.1.2 多频率 LED 闪烁

通过改变 `delay()` 参数，可以控制 LED 的闪烁频率。

```cpp
/*
 * 多频率 LED 闪烁
 * 演示不同频率的闪烁效果
 */
const int LED_PIN = 13;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // 快速闪烁（10次，100ms间隔）
  Serial.println("快速闪烁...");
  for (int i = 0; i < 10; i++) {
    digitalWrite(LED_PIN, HIGH);
    delay(100);
    digitalWrite(LED_PIN, LOW);
    delay(100);
  }
  
  delay(500);
  
  // 慢速闪烁（3次，1秒间隔）
  Serial.println("慢速闪烁...");
  for (int i = 0; i < 3; i++) {
    digitalWrite(LED_PIN, HIGH);
    delay(1000);
    digitalWrite(LED_PIN, LOW);
    delay(1000);
  }
  
  delay(500);
  
  // SOS 摩尔斯电码（···---···）
  Serial.println("SOS 信号...");
  // S: 三短
  for (int i = 0; i < 3; i++) { blink(200); }
  delay(300);
  // O: 三长
  for (int i = 0; i < 3; i++) { blink(600); }
  delay(300);
  // S: 三短
  for (int i = 0; i < 3; i++) { blink(200); }
  delay(1000);
}

void blink(int duration) {
  digitalWrite(LED_PIN, HIGH);
  delay(duration);
  digitalWrite(LED_PIN, LOW);
  delay(200);
}
```

> 💡 **知识点**：`millis()` 非阻塞延时  
> `delay()` 会阻塞程序，导致无法同时处理其他任务。实际项目中推荐使用 `millis()` 实现非阻塞延时：
> ```cpp
> unsigned long previousMillis = 0;
> const long interval = 1000;
> 
> void loop() {
>   unsigned long currentMillis = millis();
>   if (currentMillis - previousMillis >= interval) {
>     previousMillis = currentMillis;
>     // 执行定时任务
>   }
> }
> ```

## 2.2 实验二：按键控制

### 2.2.1 按键基础原理

按键是最基本的数字输入设备。Arduino 读取按键有两种方式：

| 方式 | 接线 | 未按下 | 按下 |
|------|------|--------|------|
| 外部下拉电阻 | 按键 → 引脚，引脚 → 10kΩ → GND | LOW | HIGH |
| 内部上拉电阻 | 按键一端 → 引脚，另一端 → GND | HIGH | LOW |

**推荐使用内部上拉电阻**（`INPUT_PULLUP`），无需外接电阻，更简单。

**硬件连接：**
```
按键一端 → Arduino D2
按键另一端 → GND
LED 正极 → 220Ω → Arduino D13
LED 负极 → GND
```

### 2.2.2 按键控制 LED

```cpp
/*
 * 实验名称：按键控制 LED
 * 按下按键点亮 LED，松开熄灭
 */

const int BUTTON_PIN = 2;   // 按键引脚
const int LED_PIN = 13;     // LED 引脚

void setup() {
  // 使用内部上拉电阻，按下时读到 LOW
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
  
  Serial.begin(9600);
  Serial.println("按键控制 LED 实验开始！");
  Serial.println("按下按键点亮 LED，松开熄灭");
}

void loop() {
  // 读取按键状态（使用上拉电阻，按下为 LOW）
  int buttonState = digitalRead(BUTTON_PIN);
  
  if (buttonState == LOW) {
    // 按键按下
    digitalWrite(LED_PIN, HIGH);
    Serial.println("按键按下 → LED 亮");
  } else {
    // 按键松开
    digitalWrite(LED_PIN, LOW);
  }
}
```

### 2.2.3 按键消抖

机械按键在按下/松开时会产生**抖动**（短时间内多次触发），需要消抖处理：

```cpp
/*
 * 按键消抖 + 切换 LED 状态
 * 每次按下按键，LED 状态翻转
 */

const int BUTTON_PIN = 2;
const int LED_PIN = 13;

bool ledState = false;
int lastButtonState = HIGH;
unsigned long lastDebounceTime = 0;
const unsigned long DEBOUNCE_DELAY = 50;  // 消抖时间 50ms

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int reading = digitalRead(BUTTON_PIN);
  
  // 检测到状态变化，重置消抖计时器
  if (reading != lastButtonState) {
    lastDebounceTime = millis();
  }
  
  // 超过消抖时间后，确认状态稳定
  if ((millis() - lastDebounceTime) > DEBOUNCE_DELAY) {
    // 检测到下降沿（按下）
    if (reading == LOW && lastButtonState == HIGH) {
      ledState = !ledState;  // 翻转 LED 状态
      digitalWrite(LED_PIN, ledState ? HIGH : LOW);
      Serial.print("LED 状态: ");
      Serial.println(ledState ? "开" : "关");
    }
  }
  
  lastButtonState = reading;
}
```

## 2.3 实验三：PWM 调光

### 2.3.1 PWM 原理

**PWM（脉冲宽度调制）** 是一种通过快速开关来模拟模拟信号的技术。

```
占空比 25%：  ┌─┐   ┌─┐   ┌─┐
              │ │   │ │   │ │
           ───┘ └───┘ └───┘ └───
           （亮度约 25%）

占空比 50%：  ┌──┐  ┌──┐  ┌──┐
              │  │  │  │  │  │
           ───┘  └──┘  └──┘  └──
           （亮度约 50%）

占空比 75%：  ┌───┐ ┌───┐ ┌───┐
              │   │ │   │ │   │
           ───┘   └─┘   └─┘   └─
           （亮度约 75%）
```

Arduino UNO 的 PWM 频率约为 490Hz（D3、D9、D10、D11）或 980Hz（D5、D6）。

**PWM 引脚**：D3、D5、D6、D9、D10、D11（带 `~` 标记）

**硬件连接：**
```
LED 正极 → 220Ω → Arduino D9（PWM引脚）
LED 负极 → GND
```

### 2.3.2 PWM 调光代码

```cpp
/*
 * 实验名称：PWM 调光
 * 实现 LED 渐亮、渐灭和呼吸灯效果
 */

const int LED_PIN = 9;  // 必须是 PWM 引脚

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("PWM 调光实验开始！");
}

void loop() {
  // 从暗到亮（渐亮）
  Serial.println("渐亮...");
  for (int brightness = 0; brightness <= 255; brightness++) {
    analogWrite(LED_PIN, brightness);
    delay(10);
  }
  
  delay(500);
  
  // 从亮到暗（渐灭）
  Serial.println("渐灭...");
  for (int brightness = 255; brightness >= 0; brightness--) {
    analogWrite(LED_PIN, brightness);
    delay(10);
  }
  
  delay(500);
  
  // 呼吸灯效果（使用正弦波）
  Serial.println("呼吸灯效果...");
  for (int i = 0; i < 360; i++) {
    // 使用正弦函数产生平滑的呼吸效果
    float rad = i * PI / 180.0;
    int brightness = (int)(127.5 * (1 + sin(rad)));
    analogWrite(LED_PIN, brightness);
    delay(8);
  }
}
```

### 2.3.3 电位器调光

结合模拟输入，用电位器实时控制 LED 亮度：

```cpp
/*
 * 电位器调光
 * 旋转电位器控制 LED 亮度
 */

const int POT_PIN = A0;   // 电位器接模拟引脚
const int LED_PIN = 9;    // LED 接 PWM 引脚

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int potValue = analogRead(POT_PIN);          // 读取 0~1023
  int brightness = map(potValue, 0, 1023, 0, 255);  // 映射到 0~255
  analogWrite(LED_PIN, brightness);
  
  Serial.print("电位器: ");
  Serial.print(potValue);
  Serial.print(" → 亮度: ");
  Serial.println(brightness);
  
  delay(50);
}
```

## 2.4 实验四：模拟输入

### 2.4.1 ADC 原理

Arduino UNO 内置 **10 位 ADC（模数转换器）**：
- 输入电压范围：0~5V（默认参考电压）
- 输出值范围：0~1023
- 分辨率：5V / 1024 ≈ 4.88mV

**电压计算公式：**
```
电压(V) = analogRead(pin) × 5.0 / 1023
```

**硬件连接（电压表）：**
```
被测电压 ──── Arduino A0
GND ──────── Arduino GND

注意：被测电压不能超过 5V！
```

### 2.4.2 模拟输入读取

```cpp
/*
 * 模拟输入读取
 * 读取 A0 引脚的模拟值并转换为电压
 */

const int ANALOG_PIN = A0;

void setup() {
  Serial.begin(9600);
  Serial.println("模拟输入读取实验");
  Serial.println("引脚 | 原始值 | 电压(V)");
  Serial.println("-----|--------|--------");
}

void loop() {
  int rawValue = analogRead(ANALOG_PIN);
  float voltage = rawValue * 5.0 / 1023.0;
  
  Serial.print("A0   | ");
  Serial.print(rawValue);
  Serial.print("    | ");
  Serial.print(voltage, 3);
  Serial.println("V");
  
  delay(500);
}
```

### 2.4.3 简易电压表

```cpp
/*
 * 简易电压表
 * 测量 0~5V 电压并显示
 */

const int VOLT_PIN = A0;
const float VREF = 5.0;      // 参考电压
const int ADC_MAX = 1023;    // ADC 最大值

void setup() {
  Serial.begin(9600);
  Serial.println("=== 简易电压表 ===");
}

void loop() {
  // 多次采样取平均，减少噪声
  long sum = 0;
  for (int i = 0; i < 10; i++) {
    sum += analogRead(VOLT_PIN);
    delay(5);
  }
  int avgRaw = sum / 10;
  
  float voltage = avgRaw * VREF / ADC_MAX;
  
  Serial.print("电压: ");
  Serial.print(voltage, 2);
  Serial.print("V  (ADC: ");
  Serial.print(avgRaw);
  Serial.println(")");
  
  delay(200);
}
```

## 2.5 实验五：串口通信

### 2.5.1 串口通信基础

串口（UART）是 Arduino 与电脑通信的主要方式：
- **TX（D1）**：发送数据
- **RX（D0）**：接收数据
- 常用波特率：9600、115200

> ⚠️ **注意**：上传程序时不要占用 D0/D1 引脚，否则会上传失败。

### 2.5.2 串口基础示例

```cpp
/*
 * 串口通信基础
 * 演示串口发送和接收
 */

void setup() {
  Serial.begin(9600);
  Serial.println("串口通信实验开始！");
  Serial.println("请在串口监视器中输入内容...");
}

void loop() {
  // 检查是否有数据到来
  if (Serial.available() > 0) {
    // 读取一行数据
    String input = Serial.readStringUntil('\n');
    input.trim();  // 去除首尾空白
    
    Serial.print("收到: ");
    Serial.println(input);
    
    // 简单命令处理
    if (input == "hello") {
      Serial.println("你好！我是 Arduino！");
    } else if (input == "time") {
      Serial.print("运行时间: ");
      Serial.print(millis() / 1000);
      Serial.println(" 秒");
    } else {
      Serial.print("未知命令: ");
      Serial.println(input);
    }
  }
  
  // 每秒发送一次心跳
  static unsigned long lastHeartbeat = 0;
  if (millis() - lastHeartbeat >= 5000) {
    lastHeartbeat = millis();
    Serial.print("[心跳] 运行时间: ");
    Serial.print(millis() / 1000);
    Serial.println("s");
  }
}
```

### 2.5.3 串口控制 LED

```cpp
/*
 * 串口控制 LED
 * 通过串口发送命令控制 LED
 * 命令：on/off/blink/bright:xxx
 */

const int LED_PIN = 13;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("串口控制 LED");
  Serial.println("命令: on | off | blink | bright:0-255");
}

void loop() {
  if (Serial.available() > 0) {
    String cmd = Serial.readStringUntil('\n');
    cmd.trim();
    cmd.toLowerCase();
    
    if (cmd == "on") {
      digitalWrite(LED_PIN, HIGH);
      Serial.println("LED 已开启");
    } else if (cmd == "off") {
      digitalWrite(LED_PIN, LOW);
      Serial.println("LED 已关闭");
    } else if (cmd == "blink") {
      Serial.println("开始闪烁...");
      for (int i = 0; i < 5; i++) {
        digitalWrite(LED_PIN, HIGH); delay(300);
        digitalWrite(LED_PIN, LOW);  delay(300);
      }
    } else if (cmd.startsWith("bright:")) {
      int val = cmd.substring(7).toInt();
      val = constrain(val, 0, 255);
      analogWrite(LED_PIN, val);
      Serial.print("亮度设置为: ");
      Serial.println(val);
    } else {
      Serial.print("未知命令: ");
      Serial.println(cmd);
    }
  }
}
```

## 2.6 实验六：RGB LED 控制

### 2.6.1 RGB LED 原理

RGB LED 内部包含**红（R）、绿（G）、蓝（B）**三个 LED，通过混合三种颜色可以产生各种颜色。

**共阴极 RGB LED 接线：**
```
R 引脚 → 220Ω → Arduino D9
G 引脚 → 220Ω → Arduino D10
B 引脚 → 220Ω → Arduino D11
公共阴极（最长脚）→ GND
```

**颜色混合表：**

| 颜色 | R | G | B |
|------|---|---|---|
| 红色 | 255 | 0 | 0 |
| 绿色 | 0 | 255 | 0 |
| 蓝色 | 0 | 0 | 255 |
| 黄色 | 255 | 255 | 0 |
| 青色 | 0 | 255 | 255 |
| 紫色 | 255 | 0 | 255 |
| 白色 | 255 | 255 | 255 |
| 关闭 | 0 | 0 | 0 |

### 2.6.2 RGB LED 控制代码

```cpp
/*
 * RGB LED 控制
 * 循环显示各种颜色，并实现彩虹渐变效果
 */

const int RED_PIN   = 9;
const int GREEN_PIN = 10;
const int BLUE_PIN  = 11;

void setup() {
  pinMode(RED_PIN,   OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  pinMode(BLUE_PIN,  OUTPUT);
  Serial.begin(9600);
  Serial.println("RGB LED 控制实验");
}

// 设置 RGB 颜色
void setColor(int r, int g, int b) {
  analogWrite(RED_PIN,   r);
  analogWrite(GREEN_PIN, g);
  analogWrite(BLUE_PIN,  b);
}

void loop() {
  // 显示基本颜色
  Serial.println("红色");  setColor(255, 0, 0);   delay(1000);
  Serial.println("绿色");  setColor(0, 255, 0);   delay(1000);
  Serial.println("蓝色");  setColor(0, 0, 255);   delay(1000);
  Serial.println("黄色");  setColor(255, 255, 0); delay(1000);
  Serial.println("青色");  setColor(0, 255, 255); delay(1000);
  Serial.println("紫色");  setColor(255, 0, 255); delay(1000);
  Serial.println("白色");  setColor(255, 255, 255); delay(1000);
  
  // 彩虹渐变效果
  Serial.println("彩虹渐变...");
  for (int i = 0; i < 256; i++) {
    setColor(i, 255 - i, 0);
    delay(10);
  }
  for (int i = 0; i < 256; i++) {
    setColor(255 - i, 0, i);
    delay(10);
  }
  for (int i = 0; i < 256; i++) {
    setColor(0, i, 255 - i);
    delay(10);
  }
}
```

## 2.7 实验七：中断控制

### 2.7.1 中断原理

**中断**是一种让 Arduino 暂停当前任务、立即响应特定事件的机制。

**为什么需要中断？**
- 普通轮询方式：程序不断检查按键状态，浪费 CPU 时间
- 中断方式：按键触发时自动调用中断服务函数，效率更高

**Arduino UNO 外部中断引脚：**
- **D2** → INT0
- **D3** → INT1

**中断触发模式：**

| 模式 | 说明 |
|------|------|
| `RISING` | 上升沿（LOW → HIGH）触发 |
| `FALLING` | 下降沿（HIGH → LOW）触发 |
| `CHANGE` | 电平变化时触发 |
| `LOW` | 低电平时持续触发 |

### 2.7.2 外部中断示例

```cpp
/*
 * 外部中断控制
 * 按键触发中断，LED 状态翻转
 */

const int BUTTON_PIN = 2;  // 中断引脚 INT0
const int LED_PIN = 13;

volatile bool ledState = false;  // volatile：中断中修改的变量
volatile unsigned long lastInterruptTime = 0;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
  
  // 注册中断：引脚2，下降沿触发，调用 buttonISR 函数
  attachInterrupt(digitalPinToInterrupt(BUTTON_PIN), buttonISR, FALLING);
  
  Serial.begin(9600);
  Serial.println("外部中断实验");
  Serial.println("按下按键触发中断");
}

void loop() {
  // 主循环可以做其他事情
  digitalWrite(LED_PIN, ledState ? HIGH : LOW);
  
  // 模拟主循环在做耗时任务
  delay(100);
}

// 中断服务函数（ISR）
// 注意：ISR 中不能使用 delay()，不能使用 Serial（可能导致问题）
void buttonISR() {
  // 软件消抖：两次中断间隔小于 200ms 则忽略
  unsigned long currentTime = millis();
  if (currentTime - lastInterruptTime > 200) {
    ledState = !ledState;
    lastInterruptTime = currentTime;
  }
}
```

### 2.7.3 定时器中断

使用 `TimerOne` 库实现精确定时：

```cpp
/*
 * 定时器中断
 * 每 500ms 触发一次中断，LED 闪烁
 * 需要安装 TimerOne 库
 */

#include <TimerOne.h>

const int LED_PIN = 13;
volatile bool ledState = false;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  
  // 初始化定时器，500000 微秒 = 500ms
  Timer1.initialize(500000);
  Timer1.attachInterrupt(timerISR);
  
  Serial.println("定时器中断实验");
  Serial.println("LED 每 500ms 翻转一次");
}

void loop() {
  // 主循环可以做其他事情
  Serial.print("主循环运行中... 时间: ");
  Serial.println(millis());
  delay(1000);
}

void timerISR() {
  ledState = !ledState;
  digitalWrite(LED_PIN, ledState ? HIGH : LOW);
}
```

> 💡 **中断使用注意事项：**
> - ISR 函数要尽量简短，不能调用 `delay()`
> - 在 ISR 中修改的变量必须声明为 `volatile`
> - 如果 ISR 中修改多字节变量（如 `long`），主循环中访问时需要关闭中断保护
