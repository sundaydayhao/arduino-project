- **定位**：不是一本泛泛介绍 Arduino 的入门书，而是一本围绕 **Arduino UNO Q 独特能力** 的系统实践书。

  - 会使用 Arduino IDE；
  - 了解 `setup()/loop()`、GPIO、串口、I2C/SPI 等基础；
  - 希望进入 AIoT、智能硬件、边缘 AI、智能家居与 Linux+MCU 协同开发。
- **内容结构**：
  - 前半部分：理解硬件与开发体系；
  - 中间部分：掌握联网、AI、视觉、MicroPython；
  - 后半部分：掌握 Matter、双系统协同、项目方法论与综合实战。

# 第1章 认识 Arduino UNO Q

## 1.1 为什么是 Arduino UNO Q
### 主要内容
- Arduino UNO Q 的产品定位与适用场景。
- 它在 Arduino 家族中的意义：仍保留 UNO 生态兼容性，但能力远超传统 8 位/单 MCU 板卡。

  - **Dual-brain architecture**：MPU + MCU 双处理体系；
  - **Wi-Fi 6 / BLE 5.3**；
  - **Matter / Thread 支持**；
  - **桥接 RPC**；
  - **Arduino App Lab + Arduino IDE 2.x 双开发路径**；
  - **兼容传统 UNO Shield 与新型高速扩展接口**。
- 与传统 Arduino UNO、ESP32 开发板的思维差异：
  - 从“单片机程序”转向“实时控制 + Linux 服务 + Web/API + AI”的系统开发。
- 本书读者收益与学习路线图。

# 第9章 Bridge RPC 与 MCU + Linux 协同开发

## 9.1 UNO Q 的核心竞争力：Bridge RPC
### 主要内容
- 官方重点特性：**内置 RPC/Arduino Bridge**。
- Bridge 的本质：
  - 让 MCU 与 Linux MPU 之间像“调用函数”一样通信。
- 为什么这比串口协议更高级：
  - 开发体验更自然；
  - 系统分层更清晰；
  - 更适合快速构建复杂应用。
- Bridge 在整书中的战略地位：
  - 这是 UNO Q 区别于普通开发板的关键能力之一。

## 9.2 Bridge 应用架构设计
