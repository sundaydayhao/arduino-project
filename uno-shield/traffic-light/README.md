# Arduino Uno 实现十字路口红绿灯与 3621BH 倒计时

## 1. 目标

本文说明如何在 `Arduino Uno` 上实现与 Mega 版本类似的功能：

- 东、南、西、北四个方向的红黄绿三色灯
- 每个方向一个 `3621BH` 共阳两位数码管，用于倒计时
- 基本两相位交通控制
- 支持后续扩展左转、行人按钮、蜂鸣器

重点区别在于：

- `Arduino Uno` 的 IO 数量明显少于 `Mega 2560`
- 不能再像 Mega 示例那样为每一路灯和每一个数位直接分配独立 IO
- 必须引入 `74HC595 / 74HCT595`、驱动管和动态扫描

## 2. 为什么 Uno 不能直接照搬 Mega 方案

`Arduino Uno` 可直接使用的常规 IO 资源：

- 数字口 `D0-D13`
- 模拟口 `A0-A5` 也可作为数字口使用

总数大约 `20` 路，但还要考虑：

- 串口下载和调试尽量不要长期占用 `D0/D1`
- 若后续加按键、蜂鸣器、串口模块，IO 会更紧张

而本项目的原始需求如果不做复用：

- 交通灯：`4 方向 x 3 色 = 12 路`
- 倒计时段线：`8 路`
- 4 只 `3621BH` 共 `8` 个数位位选

合计需要：

- `12 + 8 + 8 = 28` 路输出

因此 `Uno` 方案必须采用扩展输出架构。

## 3. 推荐硬件架构

### 3.1 核心方案

推荐以下组合：

- 1 x `Arduino Uno`
- 4 x `74HC595` 或 `74HCT595`
- 3 x `ULN2803A`
- 8 x `BC327` 直插 `PNP` 三极管
- 8 x `1k ohm` 到 `2.2k ohm` 基极电阻
- 8 x `10k ohm` 基极上拉电阻
- 4 x `3621BH` 共阳两位数码管
- 4 组交通灯模块或 12 颗 LED
- 1 x `5V` 有源蜂鸣器
- 外部 `5V` 电源

### 3.2 为什么推荐 4 个 74HC595 / 74HCT595

`74HC595` / `74HCT595` 是串入并出移位寄存器，一个芯片提供 `8` 路锁存输出。4 个串联后可以得到 `32` 路输出，而 Arduino 只需要 `3` 根控制线：

- `DATA` (`SER`)
- `CLOCK` (`SRCLK`)
- `LATCH` (`RCLK`)

这样 Uno 只消耗 3 根 IO，就能统一控制：

- 12 路交通灯
- 8 路数码管段线
- 8 路数码管位选

总共只使用 `28` 个输出位，还剩 4 位空余，可作为后续扩展。

### 3.3 推荐 BOM

下面的 `BOM` 以 `Arduino Uno + 4 x 3621BH + 4 组红黄绿灯 + 74HC595/74HCT595 + ULN2803A + BC327 + 5V 有源蜂鸣器` 为基准。

| 序号 | 器件 | 规格/封装 | 数量 | 备注 |
| --- | --- | --- | --- | --- |
| 1 | 主控板 | `Arduino Uno R3` 或兼容板 | 1 | `5V` 逻辑，方便直接驱动 `74HC595/74HCT595` |
| 2 | 移位寄存器 | `74HC595` 或 `74HCT595`, `DIP-16` | 4 | 推荐直插版，手工焊接方便 |
| 3 | 达林顿阵列 | `ULN2803A`, `DIP-18` | 3 | 两片给 12 路交通灯，一片给 8 路数码管段线 |

| 5 | 共阳两位数码管 | `3621BH` 或兼容型号 | 4 | 共 8 个物理数位 |
| 6 | 红色 LED | `5mm` 或对应交通灯模组 | 4 | 若使用灯组模块，则按模块数量采购 |
| 7 | 黄色 LED | `5mm` 或对应交通灯模组 | 4 | 同上 |
| 8 | 绿色 LED | `5mm` 或对应交通灯模组 | 4 | 同上 |

| 10 | 交通灯限流电阻 | `220 ohm` 到 `330 ohm`, `1/4W` | 12 | 每颗 LED 1 只 |
| 11 | 数码管段限流电阻 | `220 ohm` 到 `330 ohm`, `1/4W` | 8 | `A-G + DP` 共 8 路 |
| 12 | `BC327` 基极电阻 | `1k ohm` 到 `2.2k ohm`, `1/4W` | 8 | 推荐先用 `1k ohm` |

采购说明：

- 如果你使用的是现成红绿灯模块，`6` 到 `9` 可以替换为 `4 组交通灯模块 + 模块配套电阻`
- 推荐优先使用 `5V` 有源蜂鸣器，这样 `74HC595/74HCT595` 只需要输出开关量，不需要额外做 `PWM`
- 如果你暂时不接小数点，`DP` 对应的段电阻仍建议预留，后续调试更方便
- `BC327` 建议一次多买几只，便于筛选和备件
- `74HC595/74HCT595` 与 `ULN2803A` 建议优先选 `DIP` 直插封装，最适合手工焊接

## 5. 驱动电路建议

### 5.1 交通灯驱动

不要让 `74HC595` 直接带交通灯负载，推荐：

- `74HC595 输出 -> ULN2803A 输入`
- `ULN2803A 输出 -> 灯负极`
- `灯正极 -> +5V`

优点：

- 输出电流能力更稳
- 更适合后续换大一点的灯组
- 软件仍然只需要关心逻辑高低

### 5.2 3621BH 段线驱动

`3621BH` 是共阳数码管，段线需要“下拉导通”。

推荐：

- `74HC595 段线输出 -> ULN2803A 输入`
- `ULN2803A 输出 -> 限流电阻 -> 所有数码管对应段脚`

这种接法意味着：

- 某一段要点亮时，逻辑上要让对应 `74HC595` 输出为高
- 经 `ULN2803A` 下拉后，该段导通发光

### 5.3 3621BH 位选驱动

共阳位选需要高边驱动。对于手工焊接，优先推荐 `BC327`：

- `BC327 发射极 -> +5V`
- `BC327 集电极 -> 3621BH 的 DIG1/DIG2`
- `74HC595 位选输出 -> 1k ohm 到 2.2k ohm -> BC327 基极`
- `BC327 基极 -> 10k ohm -> +5V`

需要注意：

- 这种接法下位选是低有效，`74HC595` 输出低电平时当前数位导通
- `10k ohm` 上拉电阻用于上电默认关断，减少 `74HC595` 上电瞬间误点亮
- `BC327` 更适合手焊和洞洞板，不必再优先找 `SOP` 封装器件
- `BC327` 的脚位顺序与封装朝向要以你购买批次的数据手册为准，不要只凭经验下板
- 软件里应把“位选有效电平”做成单独常量，不要写死在业务逻辑里

## 6. Uno 推荐接线

Arduino Uno 只负责控制移位寄存器和少量扩展功能，推荐如下：

| Uno 引脚 | 用途 |
| --- | --- |
| D2 | `74HC595/74HCT595 SER` (`DATA`) |
| D3 | `74HC595/74HCT595 SRCLK` (`CLOCK`) |
| D4 | `74HC595/74HCT595 RCLK` (`LATCH`) |
| D5 | 预留 |
| D6 | 行人按钮或预留 |
| D7 | 调试 LED 或预留 |

其他建议：

- `D0/D1` 保留给串口下载与调试
- `A0-A5` 保留给未来扩展，除非你确定不会再加功能

### 6.1 实际接线总览

推荐把器件按下面的结构连接：

```text
Arduino Uno
  D2  ------------------------> 4 x 74HC595/74HCT595 的 SER(DATA)
  D3  ------------------------> 4 x 74HC595/74HCT595 的 SRCLK(CLOCK)
  D4  ------------------------> 4 x 74HC595/74HCT595 的 RCLK(LATCH)
  5V  ------------------------> 74HC595/74HCT595 / ULN2803A / BC327 / 3621BH 电源
  GND ------------------------> 全部器件共地

SR1 + SR2 --------------------> 2 x ULN2803A --------------------> 12 路交通灯阴极
                                          |
                                          +---------------------> 1 路蜂鸣器负极
SR3 --------------------------> 1 x ULN2803A -> 8 个限流电阻 ---> A B C D E F G DP 段线总线
SR4 --------------------------> 8 x 1k 电阻 -> 8 x BC327 基极
                                               8 x 10k 上拉到 +5V
                                               8 x BC327 集电极 ----> 8 个 DIG 位选
                                               8 x BC327 发射极 ----> +5V

4 x 3621BH:
  A/B/C/D/E/F/G/DP 并联到段线总线
  DIG1/DIG2 分别接各自的 BC327 集电极
```

### 6.2 4 x 74HC595 / 74HCT595 串联接法

4 片 `74HC595` / `74HCT595` 建议按 `SR1 -> SR2 -> SR3 -> SR4` 串联。

如果你使用的是图中这种 `HG74HC595N` / `74HCT595` 风格丝印，请按下面这组引脚名识别：

| 图中引脚名 | 引脚号 | 常见别名 | 说明 |
| --- | --- | --- | --- |
| `QA` | `15` | `Q0` | 并行输出 A |
| `QB` | `1` | `Q1` | 并行输出 B |
| `QC` | `2` | `Q2` | 并行输出 C |
| `QD` | `3` | `Q3` | 并行输出 D |
| `QE` | `4` | `Q4` | 并行输出 E |
| `QF` | `5` | `Q5` | 并行输出 F |
| `QG` | `6` | `Q6` | 并行输出 G |
| `QH` | `7` | `Q7` | 并行输出 H |
| `QH'` | `9` | `Q7'` / `QH'` | 串行输出，接下一片 `SER` |
| `SRCLR#` | `10` | `MR` / `SRCLR#` | 低有效清零 |
| `SRCLK` | `11` | `SHCP` / `SRCLK` | 移位时钟 |
| `RCLK` | `12` | `STCP` / `RCLK` | 锁存时钟 |
| `OE#` | `13` | `OE` / `OE#` | 低有效输出使能 |
| `SER` | `14` | `DS` / `SER` | 串行数据输入 |
| `VCC` | `16` | `VCC` | 电源正极 |
| `GND` | `8` | `GND` | 地 |

公共引脚连接：

| 引脚 | 连接方式 |
| --- | --- |
| `VCC` `pin16` | 接 `+5V` |
| `GND` `pin8` | 接 `GND` |
| `OE#` `pin13` | 直接接 `GND`，始终使能输出 |
| `SRCLR#` `pin10` | 直接接 `+5V`，禁止异步清零 |
| `SRCLK` `pin11` | 四片并联后接 `Arduino D3` |
| `RCLK` `pin12` | 四片并联后接 `Arduino D4` |

串联关系：

| 起点 | 终点 |
| --- | --- |
| `Arduino D2` | `SR1 SER pin14` |
| `SR1 QH' pin9` | `SR2 SER pin14` |
| `SR2 QH' pin9` | `SR3 SER pin14` |
| `SR3 QH' pin9` | `SR4 SER pin14` |

布线注意：

- 每片 `74HC595/74HCT595` 的 `VCC` 与 `GND` 之间各放 1 只 `100nF` 去耦电容
- `SR1` 和 `SR2` 专门给交通灯使用
- `SR3` 专门给数码管段线使用
- `SR4` 专门给 8 个位选使用

### 6.3 交通灯实际接线

推荐把 `12` 路交通灯分给两片 `ULN2803A`，每路接法都是“高边经电阻到 `+5V`，低边由 `ULN2803A` 下拉”。

单路接法：

```text
+5V -> 220R/330R -> LED 阳极
LED 阴极 -> ULN2803A OUTn
ULN2803A INn <- 74HC595 Qn
ULN2803A GND -> GND
```

交通灯通道分配示例：

| 功能 | `74HC595` 输出 | `ULN2803A` 通道 |
| --- | --- | --- |
| North Red | `SR1 Q0` | `LAMP_DRV_A IN1/OUT1` |
| North Yellow | `SR1 Q1` | `LAMP_DRV_A IN2/OUT2` |
| North Green | `SR1 Q2` | `LAMP_DRV_A IN3/OUT3` |
| South Red | `SR1 Q3` | `LAMP_DRV_A IN4/OUT4` |
| South Yellow | `SR1 Q4` | `LAMP_DRV_A IN5/OUT5` |
| South Green | `SR1 Q5` | `LAMP_DRV_A IN6/OUT6` |
| East Red | `SR1 Q6` | `LAMP_DRV_A IN7/OUT7` |
| East Yellow | `SR1 Q7` | `LAMP_DRV_A IN8/OUT8` |
| East Green | `SR2 Q0` | `LAMP_DRV_B IN1/OUT1` |
| West Red | `SR2 Q1` | `LAMP_DRV_B IN2/OUT2` |
| West Yellow | `SR2 Q2` | `LAMP_DRV_B IN3/OUT3` |
| West Green | `SR2 Q3` | `LAMP_DRV_B IN4/OUT4` |
| Buzzer | `SR2 Q4` | `LAMP_DRV_B IN5/OUT5` |

说明：

- `LAMP_DRV_B` 的 `IN6` 到 `IN8` 可先留空，后续可扩展左转灯或行人灯
- `ULN2803A` 的 `COM pin10` 在 LED 负载场景下可不接

### 6.4 蜂鸣器实际接线

默认推荐 `5V` 有源蜂鸣器，直接由 `ULN2803A` 做低边开关。

接法如下：

```text
+5V ---------> 蜂鸣器正极
蜂鸣器负极 ---> LAMP_DRV_B OUT5
SR2 Q4 ------> LAMP_DRV_B IN5
GND ---------> LAMP_DRV_B GND
```

控制逻辑：

- `SR2 Q4 = HIGH` 时，`ULN2803A` 导通，蜂鸣器响
- `SR2 Q4 = LOW` 时，`ULN2803A` 截止，蜂鸣器停

使用建议：

- 若只需要提示音，例如黄灯阶段短鸣、相位切换长鸣，优先用有源蜂鸣器
- 若你后续想播放不同频率音调，应该改成无源蜂鸣器，并改用 `Arduino D5` 加三极管驱动，不能继续只靠 `74HC595` 输出静态高低电平

### 6.5 数码管段线实际接线

`3621BH` 是共阳数码管，因此 `A` 到 `G` 以及 `DP` 统一由 `ULN2803A` 负责下拉导通。

单段接法：

```text
3621BH 某位公共阳极 <- BC327 高边位选导通后得到 +5V
3621BH 某段引脚 -> 220R/330R -> ULN2803A OUTn
ULN2803A INn <- SR3 Qn
```

段线分配：

| 段 | `SR3` 输出 | `SEG_DRV` 通道 | `3621BH` 引脚 |
| --- | --- | --- | --- |
| A | `SR3 Q0` | `IN1/OUT1` | `pin3` |
| B | `SR3 Q1` | `IN2/OUT2` | `pin9` |
| C | `SR3 Q2` | `IN3/OUT3` | `pin8` |
| D | `SR3 Q3` | `IN4/OUT4` | `pin6` |
| E | `SR3 Q4` | `IN5/OUT5` | `pin7` |
| F | `SR3 Q5` | `IN6/OUT6` | `pin4` |
| G | `SR3 Q6` | `IN7/OUT7` | `pin1` |
| DP | `SR3 Q7` | `IN8/OUT8` | `pin2` |

4 只 `3621BH` 的对应段脚全部并联：

- 4 只数码管的 `A pin3` 全部并在一起，再接到 `A` 段总线
- 其余 `B/C/D/E/F/G/DP` 也按同样方式并联

### 6.6 数码管位选实际接线

8 个物理数位分别用 8 只 `BC327` 做高边开关。

单个数位接法：

```text
           +5V
            |
         E  |
SR4 Qn --1k-+--B  BC327
            |
           10k
            |
           +5V

BC327 C ----> 3621BH 的 DIG1 或 DIG2
```

位选分配示例：

| 数位 | `SR4` 输出 | `BC327` 集电极连接 |
| --- | --- | --- |
| North 十位 | `SR4 Q0` | 北向数码管 `DIG1 pin10` |
| North 个位 | `SR4 Q1` | 北向数码管 `DIG2 pin5` |
| South 十位 | `SR4 Q2` | 南向数码管 `DIG1 pin10` |
| South 个位 | `SR4 Q3` | 南向数码管 `DIG2 pin5` |
| East 十位 | `SR4 Q4` | 东向数码管 `DIG1 pin10` |
| East 个位 | `SR4 Q5` | 东向数码管 `DIG2 pin5` |
| West 十位 | `SR4 Q6` | 西向数码管 `DIG1 pin10` |
| West 个位 | `SR4 Q7` | 西向数码管 `DIG2 pin5` |

位选逻辑：

- `SR4 Qn = LOW` 时，`BC327` 导通，该数位点亮
- `SR4 Qn = HIGH` 时，`BC327` 截止，该数位熄灭
- 软件里应把位选定义成低有效，避免显示扫描逻辑写反

## 8. 软件框架

Uno 版本的软件建议分成两层。

### 8.1 业务层

业务层与 Mega 版本基本一致，仍然保留：

- `LampColor`
- `Direction`
- `StageDefinition`
- `IntersectionController`

业务层只关心：

- 当前阶段是什么
- 哪个方向亮什么灯
- 每个方向应该显示多少倒计时

### 8.2 硬件抽象层

Uno 版本需要新增两个关键模块：

#### `ShiftRegisterBus`

职责：

- 维护 32 位输出缓冲区
- 通过 `shiftOut()` 或 SPI 把 32 位一次性刷新到 4 个 `74HC595`
- 提供 `setBit(index, value)` 接口

#### `DisplayScanner`

职责：

- 维护 8 个物理数位的显示缓存
- 每次只使能 1 个数位
- 设置对应段码
- 调用 `ShiftRegisterBus.flush()` 输出到移位寄存器

#### `LampDriver`

职责：

- 把 `North/South/East/West` 的红黄绿灯状态映射到 32 位缓冲区中的对应位
- 不直接操作 Arduino 引脚

## 9. 推荐调度方式

### 9.1 主状态机

主状态机继续使用 `millis()`：

- 绿灯 `15s`
- 黄灯 `3s`
- 全红 `2s`

### 9.2 数码管扫描

推荐每 `1ms` 到 `2ms` 扫描一个物理数位：

- 系统共 `8` 个数位
- 每轮完整扫描约 `8ms` 到 `16ms`
- 整体刷新率约 `62.5Hz` 到 `125Hz`

这个范围通常不会肉眼闪烁。

实现方式有两种：

1. 在 `loop()` 中基于 `micros()` 高频轮询
2. 用 `Timer2` 中断定时扫描

对于课程设计，优先推荐第一种：

- 易理解
- 易调试
- 不需要先处理复杂中断共享问题

## 10. 软件执行流程

### 10.1 `setup()`

- 初始化 `ShiftRegisterBus`
- 清空 32 位输出缓冲
- 初始化交通灯控制器
- 初始化显示扫描器
- 设置初始交通相位

### 10.2 `loop()`

- 高频调用 `displayScanner.service()`
- 周期性推进 `IntersectionController`
- 把新的灯状态写入移位寄存器缓冲
- 把新的倒计时拆成 8 个物理数位
- 刷新输出

## 11. 与 Mega 方案的差异

| 项目 | Mega 方案 | Uno 方案 |
| --- | --- | --- |
| IO 分配 | 可大量直连 | 必须扩展输出 |
| 显示驱动 | 可直接单独接线 | 更适合统一扫描 |
| 电路复杂度 | 低 | 中等 |
| 软件复杂度 | 低到中 | 中到高 |
| 成本 | 稍高 | 主控低，但外围器件更多 |

## 12. 风险与注意事项

- `74HC595` 本身不适合直接驱动较大电流负载，必须加驱动级
- 数码管扫描频率过低会闪烁
- 若刷新位选和段码的顺序不对，会出现重影
- 若多个方向同时大电流点亮，外部 `5V` 电源必须稳定
- 若单个数位同时点亮很多段，优先把 `BC327` 基极电阻取小一点，例如 `1k ohm`
- `Uno` RAM 很小，代码结构要清晰，但不要引入过重的动态内存使用

## 13. 实施建议

推荐按下面顺序推进：

1. 先只接 1 只 `3621BH`，验证段码和位选极性
2. 再扩展到 4 只数码管，验证动态扫描是否稳定
3. 加入 4 个方向三色灯
4. 最后接入完整交通相位状态机

这样排错成本最低。

## 14. 结论

`Arduino Uno` 完全可以实现这个十字路口红绿灯系统，但前提是：

- 不再使用“每个负载独占一个 IO”的做法
- 使用 `74HC595 + ULN2803A + BC327 高边位选驱动`
- 软件上采用“状态机 + 动态扫描 + 输出缓冲”

如果只是为了更快做出演示板，`Mega 2560` 更直接；如果你希望在 `Uno` 上完成更典型的嵌入式资源受限设计，这套方案是合理的。
