# Motor Driver Shield（电机驱动 Shield）

基于 Arduino UNO R3 + TB6612FNG 的双路直流电机驱动 Shield，支持 PWM 调速、4 路舵机输出、编码器读取和串口命令控制。

---

## 📁 项目结构

```
shield/motor/
├── src/
│   └── motor_shield.ino    # Arduino 主程序
└── README.md
```

|------|------|
| 🚗 双路直流电机 | TB6612FNG，1.2A/通道，峰值 3.2A |
| ⚡ PWM 调速 | 速度 0–255 可调 |
| 🔄 四向运动 | 前进、后退、左转、右转、停止 |
| 🦾 4 路舵机 | 使用 Arduino Servo 库，角度 0–180° |

## 🔌 接线说明

### TB6612FNG 电机驱动模块

| TB6612FNG 引脚 | Arduino 引脚 | 说明 |
|---------------|-------------|------|
| PWMA | **Pin 3** | 电机A速度（PWM） |
| AIN1 | **Pin 4** | 电机A方向控制1 |
| AIN2 | **Pin 5** | 电机A方向控制2 |
| PWMB | **Pin 9** | 电机B速度（PWM） |
| BIN1 | **Pin 7** | 电机B方向控制1 |
| BIN2 | **Pin 8** | 电机B方向控制2 |
| STBY | **Pin 6** | 待机控制（HIGH=使能，LOW=待机） |
| VCC | 5V | 逻辑电源 |
| GND | GND | 公共地 |
| VM | 电机电源（6–12V） | **独立供电，不接 Arduino 5V！** |
| AO1/AO2 | 电机A两端 | 直流电机A |
| BO1/BO2 | 电机B两端 | 直流电机B |

> ⚠️ **VM（电机电源）必须独立供电**，不能使用 Arduino 的 5V，否则会损坏 Arduino！

### 直接使用 TB6612FNG 芯片

如果你不用现成模块，而是直接使用 **TB6612FNG 芯片（SSOP-24）**，建议按 Toshiba 官方数据手册和参考原理图补齐最小外围电路。

#### 必需外围元件

| 位号 | 推荐值 | 连接位置 | 作用 |
|------|--------|----------|------|
| `C_VCC1` | 10uF / 10V 以上 | `VCC` 到 `GND` | 逻辑电源滤波 |
| `C_VCC2` | 0.1uF 陶瓷 | `VCC` 到 `GND` | 逻辑电源高频去耦 |
| `C_VM1` | 10uF / 25V 以上 | `VM` 到 `PGND/GND` | 电机电源储能滤波 |
| `C_VM2` | 0.1uF 陶瓷 | `VM` 到 `PGND/GND` | 电机电源高频去耦 |
| `C_MA`（可选） | 0.01uF ~ 0.1uF | 电机A两端 | 抑制电刷火花干扰 |
| `C_MB`（可选） | 0.01uF ~ 0.1uF | 电机B两端 | 抑制电刷火花干扰 |
| `R/C Snubber`（可选） | 需按电机调试 | 输出端到地或跨电机 | 强干扰场景下抑制尖峰和 EMI |

> 官方参考板 BOM 使用了 `VCC: 10uF + 0.1uF`、`VM: 10uF + 0.1uF`；输出端的 RC 吸收网络预留了焊盘，但默认 **Not Mount**。

#### 芯片电源和外围连接规则

1. **`VM`（电机电源）** 接电机电池正极，例如 `6V~12V` 电池组。
2. **`VCC`（逻辑电源）** 接 Arduino UNO 的 `5V`。
3. **`GND` 与 `PGND` 必须和 Arduino GND、电机电源负极共地。**
4. **`VM` 与 `VCC` 不能直接短接。**
5. **`VM` 去耦电容和 `VCC` 去耦电容要尽量靠近芯片电源脚摆放。**
6. **电机输出线（AO/BO）走线尽量粗、尽量短；PGND 回流路径也尽量粗。**
7. TB6612FNG 内部已带续流路径，**普通直流电机应用一般不需要再外接续流二极管**。

#### TB6612FNG 芯片逐脚连线

下表按 **TB6612FNG SSOP-24** 引脚功能列出，可直接照着画原理图：

| 芯片引脚 | 名称 | 连接到哪里 | 说明 |
|---------|------|------------|------|

| `5, 6` | `AO2` | 电机A另一端 | 两个同名脚并在一起后接出去 |

#### 去耦电容连接方式

| 电容 | 一端连接 | 另一端连接 | 备注 |
|------|----------|------------|------|
| `C_VCC1 10uF` | `VCC(20)` | `GND(18)` | 尽量贴近芯片 |
| `C_VCC2 0.1uF` | `VCC(20)` | `GND(18)` | 尽量比电解更靠近引脚 |
| `C_VM1 10uF` | `VM(13/14/24)` | `PGND/GND` | 建议靠近 `VM` 脚 |
| `C_VM2 0.1uF` | `VM(13/14/24)` | `PGND/GND` | 高频旁路，必须靠近 |
| `C_MA`（可选） | 左电机一端 | 左电机另一端 | 电机本体两端焊接更有效 |
| `C_MB`（可选） | 右电机一端 | 右电机另一端 | 电机本体两端焊接更有效 |

#### 可直接照抄的简化原理图

```text
Arduino UNO                          TB6612FNG 芯片
-----------                          ------------------------------
5V    -----------------------------> VCC (20)
GND   -----------------------------> GND (18)
GND   -----------------------------> PGND1 (3,4)
GND   -----------------------------> PGND2 (9,10)
D3    -----------------------------> PWMA (23)
D4    -----------------------------> AIN1 (21)
D5    -----------------------------> AIN2 (22)
D6    -----------------------------> STBY (19)
D7    -----------------------------> BIN1 (17)
D8    -----------------------------> BIN2 (16)
D9    -----------------------------> PWMB (15)

电池 +6V~12V ----------------------> VM (13,14,24)
电池 GND ---------------------------> 公共地

左电机两端 <-----------------------> AO1 (1,2), AO2 (5,6)
右电机两端 <-----------------------> BO1 (11,12), BO2 (7,8)

VCC (20) --- 10uF --- GND
VCC (20) --- 0.1uF -- GND
VM  (...) --- 10uF --- PGND/GND
VM  (...) --- 0.1uF -- PGND/GND
```

#### 设计注意事项

- `STBY` 不能悬空。你当前程序使用 `D6` 控制，所以直接接到 `D6` 即可。
- `VM` 电流脉动较大，`VM` 走线和地回流建议加宽，最好先走到电容，再进芯片。
- 如果电机刷火严重、串口会乱码、Arduino 会复位，优先增加电机两端的抑制电容，并检查电源地回路。
- 如果电机方向和程序定义相反，直接交换某个电机的两根线即可，不需要改硬件。

## 🚀 使用步骤

1. **连接硬件**（按接线表）
2. **电机电源独立供电**（6–12V，不要用 Arduino 5V）
3. **上传代码**：`src/motor_shield.ino`
4. **打开串口监视器**（波特率 9600）
5. **发送命令测试**：
   - `V150` → 设置速度为 150
   - `F` → 前进
   - `S` → 停止
   - `D` → 运行 Demo

## 🔍 常见问题

### 电机不转
- 检查 STBY 引脚是否为 HIGH（代码中 `setStandby(false)` 会拉高）
- 确认 VM 接了电机电源（6–12V），不是 Arduino 5V
- 用万用表测量 AO1/AO2 输出电压

### 电机转向相反
- 交换电机两根线（AO1↔AO2 或 BO1↔BO2）
- 或修改代码中 `motorA()` / `motorB()` 的 AIN1/AIN2 逻辑

### 舵机抖动
- 多个舵机同时工作时电流不足，使用外部 5V 电源
- 确认舵机 GND 与 Arduino GND 共地

### 编码器计数不准
- 确认编码器 CLK 接 Pin 2（INT0），DIR 接 A0
- 检查编码器供电（通常 3.3V 或 5V）
- 编码器B使用轮询，高速时可能丢脉冲，建议改用 Pin 3（INT1）

### Arduino 重启 / 电源不稳
- 电机启动瞬间电流大，会导致 Arduino 电压跌落
- 在 Arduino 5V 和 GND 之间加 100μF 电解电容
- 电机电源和 Arduino 电源分开，只共 GND
