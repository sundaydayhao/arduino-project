# Motor Driver Shield（电机驱动 Shield）

基于 Arduino UNO R3 + TB6612FNG 的双路直流电机驱动 Shield，支持 PWM 调速、4 路舵机输出、编码器读取和串口命令控制。

---

## 📁 项目结构

```
shield/motor/
├── src/
│   └── motor_shield.ino    # Arduino 主程序
└── README.md
```

---

## ✨ 功能概览

| 功能 | 说明 |
|------|------|
| 🚗 双路直流电机 | TB6612FNG，1.2A/通道，峰值 3.2A |
| ⚡ PWM 调速 | 速度 0–255 可调 |
| 🔄 四向运动 | 前进、后退、左转、右转、停止 |
| 🦾 4 路舵机 | 使用 Arduino Servo 库，角度 0–180° |
| 📊 编码器读取 | 电机A中断驱动，电机B轮询 |
| 📡 串口控制 | 命令行控制所有功能 |
| 🎬 Demo 模式 | 自动演示动作序列 |

## 🔧 硬件清单

| 序号 | 元件 | 规格 | 数量 |
|------|------|------|------|
| 1 | Arduino UNO R3 | ATmega328P | 1 |
| 2 | TB6612FNG 电机驱动模块 | 双路，1.2A/通道 | 1 |
| 3 | 直流减速电机 | 3–12V，带编码器（可选） | 2 |
| 4 | 舵机 | SG90 或 MG996R | 1–4 |
| 5 | 电机电源 | 6–12V 锂电池或电源适配器 | 1 |
| 6 | 杜邦线 | 若干 | — |

> 💡 **TB6612FNG vs L298N**：TB6612FNG 效率更高（无压降损失），体积更小，推荐优先使用。

## 🔌 接线说明

### TB6612FNG 电机驱动模块

| TB6612FNG 引脚 | Arduino 引脚 | 说明 |
|---------------|-------------|------|
| PWMA | **Pin 3** | 电机A速度（PWM） |
| AIN1 | **Pin 4** | 电机A方向控制1 |
| AIN2 | **Pin 5** | 电机A方向控制2 |
| PWMB | **Pin 9** | 电机B速度（PWM） |
| BIN1 | **Pin 7** | 电机B方向控制1 |
| BIN2 | **Pin 8** | 电机B方向控制2 |
| STBY | **Pin 6** | 待机控制（HIGH=使能，LOW=待机） |
| VCC | 5V | 逻辑电源 |
| GND | GND | 公共地 |
| VM | 电机电源（6–12V） | **独立供电，不接 Arduino 5V！** |
| AO1/AO2 | 电机A两端 | 直流电机A |
| BO1/BO2 | 电机B两端 | 直流电机B |

> ⚠️ **VM（电机电源）必须独立供电**，不能使用 Arduino 的 5V，否则会损坏 Arduino！

### 电机方向控制逻辑

| AIN1 | AIN2 | 电机A状态 |
|------|------|---------|
| HIGH | LOW | 正转 |
| LOW | HIGH | 反转 |
| LOW | LOW | 刹车（短路制动） |
| HIGH | HIGH | 刹车（短路制动） |

### 舵机

| 舵机 | Arduino 引脚 | 说明 |
|------|-------------|------|
| 舵机1 | **Pin 10** | 信号线（橙/黄色） |
| 舵机2 | **Pin 11** | 信号线 |
| 舵机3 | **Pin 12** | 信号线 |
| 舵机4 | **Pin 13** | 信号线 |
| 所有舵机 VCC | 5V 或外部 5V | 电源（多个舵机建议外部供电） |
| 所有舵机 GND | GND | 地 |

> ⚠️ 多个舵机同时工作电流较大，建议使用外部 5V 电源供电，GND 与 Arduino 共地。

### 编码器（可选）

| 编码器 | Arduino 引脚 | 说明 |
|-------|-------------|------|
| 编码器A CLK | **Pin 2** | 中断驱动（INT0，下降沿） |
| 编码器A DIR | **A0** | 方向信号 |
| 编码器B CLK | **A1** | 轮询读取 |
| 编码器B DIR | **A2** | 方向信号 |

```

2. 左转 0.5 秒
3. 前进 1 秒
4. 右转 0.5 秒
5. 后退 1 秒
6. 原地旋转 1 秒
7. 停止
8. 舵机1/2 扫描 0°→180°→0°

```

## 🚀 使用步骤

1. **连接硬件**（按接线表）
2. **电机电源独立供电**（6–12V，不要用 Arduino 5V）
3. **上传代码**：`src/motor_shield.ino`
4. **打开串口监视器**（波特率 9600）
5. **发送命令测试**：
   - `V150` → 设置速度为 150
   - `F` → 前进
   - `S` → 停止
   - `D` → 运行 Demo

## 🔍 常见问题

### 电机不转
- 检查 STBY 引脚是否为 HIGH（代码中 `setStandby(false)` 会拉高）
- 确认 VM 接了电机电源（6–12V），不是 Arduino 5V
- 用万用表测量 AO1/AO2 输出电压

### 电机转向相反
- 交换电机两根线（AO1↔AO2 或 BO1↔BO2）
- 或修改代码中 `motorA()` / `motorB()` 的 AIN1/AIN2 逻辑

### 舵机抖动
- 多个舵机同时工作时电流不足，使用外部 5V 电源
- 确认舵机 GND 与 Arduino GND 共地

### 编码器计数不准
- 确认编码器 CLK 接 Pin 2（INT0），DIR 接 A0
- 检查编码器供电（通常 3.3V 或 5V）
- 编码器B使用轮询，高速时可能丢脉冲，建议改用 Pin 3（INT1）

### Arduino 重启 / 电源不稳
- 电机启动瞬间电流大，会导致 Arduino 电压跌落
- 在 Arduino 5V 和 GND 之间加 100μF 电解电容
- 电机电源和 Arduino 电源分开，只共 GND

## 💡 扩展建议

| 扩展方向 | 建议方案 |
|---------|---------|
| 超声波避障 | 添加 HC-SR04（Trig=A3, Echo=A4），检测障碍物自动停车 |
| 蓝牙遥控 | 添加 HC-05（SoftwareSerial），手机 App 发送 F/B/L/R |
| PID 速度控制 | 利用编码器反馈实现精确速度闭环控制 |
| 循迹功能 | 添加红外循迹模块（3路），实现自动循线 |
| 四驱小车 | 使用两块 TB6612FNG 模块，控制 4 个电机 |
