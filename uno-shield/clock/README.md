# Arduino Uno 独立数码管时钟/温湿度显示

这个方案不使用 TM1637 模块，直接用多个**独立一位数码管**做动态扫描显示。你现在使用的是 **18101BS 共阳型数码管**，所以下面的硬件说明已经按**共阳动态扫描**整理。推荐做成 **6 位数码管**，这样能完整显示：

- 时间：`HH.MM.SS`
- 日期：`YY.MM.DD`
- 温度：`t23.5C`
- 湿度：`h56.2H`

代码文件见：[uno_6digit_clock.ino](D:\workspace\arduino-project\uno-shield\clock\uno_6digit_clock.ino)

## 1. 器件清单

- Arduino Uno 1 块
- 独立一位七段数码管 6 个
- DS1302 RTC 芯片 1 颗
- DIP-8 底座或转接板 1 个
  如果你手上不是直插封装，建议先焊到转接板，再用杜邦线连接
- 32.768kHz 时钟晶振 1 个
- DHT11 或 DHT22 温湿度模块 1 个
- 轻触按键 4 个
- `BC327` PNP 三极管 6 个
- 330 欧电阻 8 个
  每个段线一只，`a b c d e f g dp` 各 1 个
- 1k 欧电阻 6 个
  每个三极管基极一只
- 10k 欧电阻 3 个
  其中 1 个给 DHT 数据线做上拉，1 个给按键电阻分压做上拉，1 个给 `数值减` 键分压
- 3.3k 欧电阻 1 个
  给 `数值加` 键做按键分压
- 1k 欧电阻 1 个
  给 `选择` 键做按键分压
- 0.1uF 去耦电容 1 个
  紧贴 `DS1302` 的电源脚
- CR2032 纽扣电池 1 个
  可选，用于 `DS1302` 备用供电；如果不需要掉电保持，可不接
- 面包板、导线若干

## 2. 显示器连接方式

默认按 **18101BS 共阳极数码管** 说明，且使用**动态扫描**。

核心思路：

- 6 个数码管的 `a` 段全部并在一起
- 6 个数码管的 `b` 段全部并在一起
- 其余 `c d e f g dp` 也分别并在一起
- 每一组段线只接一个限流电阻
- 每个数码管的公共阳极单独接一个 `BC327` 做位选
- 程序快速轮流点亮 6 位，人眼看起来就是同时亮

共阳动态扫描的工作方式：

- 某一位被选中时，它的公共阳极被接到 `5V`
- 需要点亮的段线由 Arduino 输出 `LOW` 导通
- 不需要点亮的段线输出 `HIGH`

## 3. Arduino 引脚分配

### 段线

- `D2` -> `a`
- `D3` -> `b`
- `D4` -> `c`
- `D5` -> `d`
- `D6` -> `e`
- `D7` -> `f`
- `D8` -> `g`
- `D9` -> `dp`

每一条段线都要串一个 `330R` 电阻。

### 位选

- 第 1 位公共阳极 -> 三极管 1 集电极，基极控制脚 `D10`
- 第 2 位公共阳极 -> 三极管 2 集电极，基极控制脚 `D11`
- 第 3 位公共阳极 -> 三极管 3 集电极，基极控制脚 `D12`
- 第 4 位公共阳极 -> 三极管 4 集电极，基极控制脚 `D13`
- 第 5 位公共阳极 -> 三极管 5 集电极，基极控制脚 `D1`
- 第 6 位公共阳极 -> 三极管 6 集电极，基极控制脚 `A1`

每个 `BC327` 连接方式：

- 发射极 -> `5V`
- 集电极 -> 对应那一位数码管的公共阳极
- 基极 -> 通过 `1k` 电阻接到 Arduino 位选引脚
- 基极再通过 `10k` 电阻上拉到 `5V`，防止上电复位时误导通

`BC327` 使用注意：

- 请按你手上器件的数据手册确认引脚顺序，不要只凭经验接
- 很多 `TO-92` 封装的 `BC327` 在“平面朝向自己、引脚朝下”时是 `C-B-E`，但仍以数据手册为准

位选逻辑：

- Arduino 位选脚输出 `LOW` -> 对应数码管这一位导通
- Arduino 位选脚输出 `HIGH` -> 对应数码管这一位关闭

补充说明：

- 由于 `A0` 改给 4 键分压输入，所以第 5 位位选改到了 `D1(TX)`
- 这样接线后，`D1` 不再适合做串口调试输出

## 4. RTC 和温湿度模块接线

### DS1302 芯片直连

当前代码默认使用这 3 根控制线：

- `CE/RST` -> `A3`
- `I/O` -> `A4`
- `SCLK` -> `A5`

电源和晶振连接：

- `VCC2` -> `5V`
- `GND` -> `GND`
- `VCC1` -> 纽扣电池正极
- 纽扣电池负极 -> `GND`
- `X1` 与 `X2` 之间直接接一个 `32.768kHz` 晶振
- `VCC2` 与 `GND` 之间并一个 `0.1uF` 去耦电容，尽量靠近芯片

如果你不需要掉电保持：

- `VCC1` 可以先接 `GND`

`DS1302` 是三线串行接口，不是 I2C，所以：

- 不需要 `SDA/SCL` 上拉电阻
- 也不用占用 `Wire` 库

如果你是用杜邦线搭面包板，建议：

- 芯片尽量靠近 `32.768kHz` 晶振
- `X1/X2` 走线尽量短
- 先把 `CE/I/O/SCLK` 接好，再接后备电池

注意：

- `DS1302` 需要外接 `32.768kHz` 晶振
- `DS1302` 精度通常不如 `DS3231`
- 不要开启涓流充电去给普通 `CR2032` 充电，当前代码也没有启用这个功能

### DHT11 / DHT22

- `VCC` -> `5V`
- `GND` -> `GND`
- `DATA` -> `A2`
- `DATA` 与 `5V` 之间接 `10k` 上拉

### 四个按键

当前代码使用 `A0` 读取 4 个按键，方式是**一个模拟口 + 电阻分压**，不是 4 根独立 IO。

- `A0` 先通过一个 `10k` 电阻上拉到 `5V`
- `功能` 键：`A0` 按下时直接接到 `GND`
- `选择` 键：`A0` 按下时通过 `1k` 电阻接到 `GND`
- `数值加` 键：`A0` 按下时通过 `3.3k` 电阻接到 `GND`
- `数值减` 键：`A0` 按下时通过 `10k` 电阻接到 `GND`

注意：

- 这 4 个键建议一次只按一个
- 如果你坚持每个键都独占一根 IO，Uno 当前引脚已经不够，需要增加扩展芯片，或者减少显示占脚

## 5. 接线示意

下面是逻辑示意，不是精确原理图：

```text
Arduino D2  --330R--+-- 数码管1 a
                    +-- 数码管2 a
                    +-- 数码管3 a
                    +-- 数码管4 a
                    +-- 数码管5 a
                    +-- 数码管6 a

Arduino D3  --330R--+-- 所有数码管 b
Arduino D4  --330R--+-- 所有数码管 c
Arduino D5  --330R--+-- 所有数码管 d
Arduino D6  --330R--+-- 所有数码管 e
Arduino D7  --330R--+-- 所有数码管 f
Arduino D8  --330R--+-- 所有数码管 g
Arduino D9  --330R--+-- 所有数码管 dp

Arduino A3 ----------- DS1302 CE/RST
Arduino A4 ----------- DS1302 I/O
Arduino A5 ----------- DS1302 SCLK

Arduino A0 ----+------ 10k ---- 5V
               |
               +------ 按键1 功能 ------ GND
               |
               +------ 按键2 选择 -- 1k -- GND
               |
               +------ 按键3 加值 - 3.3k - GND
               |
               +------ 按键4 减值 -- 10k -- GND

DS1302 VCC2 ---------- 5V
DS1302 GND ----------- GND
DS1302 VCC1 ---------- CR2032 +
CR2032 - ------------- GND
DS1302 X1 --- 32.768kHz --- X2

                 +--10k-- 5V
                 |
Arduino D10 --1k-+--B  BC327(1)
                    C---- 数码管1 公共阳极
                    E---- 5V

                 +--10k-- 5V
                 |
Arduino D11 --1k-+--B  BC327(2)
                    C---- 数码管2 公共阳极
                    E---- 5V

... 其余位完全相同
```

注意：

- `E` 发射极是**直接接 `5V`**
- `10k` 电阻是从 `B` 基极**上拉到 `5V`**
- `1k` 电阻是 Arduino 引脚到 `B` 基极的限流电阻

## 6. 按键操作

默认交互逻辑如下：

- `功能` 短按：切换显示页面
- `选择` 短按：保持当前页面约 10 秒，不再自动轮播
- `选择` 长按：进入时间/日期设置模式
- `数值加` 短按：在普通显示下切到上一页；在设置模式下当前字段加 1
- `数值减` 短按：在普通显示下切到下一页；在设置模式下当前字段减 1

设置模式下：

- 当前正在编辑的字段会闪烁
- `选择` 短按：切换到下一个字段
- `功能` 短按：保存到 `DS1302` 并退出设置
- `功能` 长按：放弃本次修改并退出设置
- 长按 `数值加/数值减` 会连续调整

设置字段顺序：

- `时`
- `分`
- `秒`
- `年`
- `月`
- `日`

## 9. 显示逻辑

程序每隔几秒自动轮播：

- 时间：`12.34.56`
- 日期：`26.04.06`
- 温度：`t23.5C`
- 湿度：`h56.2H`

说明：

- 时间页中间的小数点会闪烁，起到冒号效果
- 日期页用两个小数点分隔年、月、日
- 温度和湿度页左边用 `t` / `h` 标识

## 10. 调试建议

- 如果所有段都乱亮，优先检查 `BC327` 是否接反、基极是否有 `10k` 上拉，以及公共端是否接到**公共阳极**
- 如果只有一位亮，检查对应位选三极管接法
- 如果段显示顺序错了，确认 `a~g, dp` 的引脚是否接对
- 如果温湿度一直是横杠，检查 DHT 类型是否设置正确，以及数据线上拉是否存在
- 如果时间不走，检查 `DS1302` 的 `CE/I/O/SCLK` 是否分别接到 `A3/A4/A5`
- 如果时间总是乱跳，优先检查 `32.768kHz` 晶振是否接在 `X1/X2`，并尽量缩短这两根线
- 如果掉电后时间丢失，检查 `VCC1` 到纽扣电池的连接
- 如果按键无反应，先测 `A0` 空闲时是否接近 `5V`，再逐个按键测是否能得到不同电压
- 如果上传程序后第 5 位不亮，检查 `D1` 到该位三极管基极的连接；注意此脚已经不再适合串口调试

## 11. 重要限制

- 这个方案默认你有 **6 个独立一位共阳数码管**
- 如果你只有 **4 位**，也能做，但显示策略要改成分页显示，例如只显示 `HHMM`、`MMDD`、`23.5`
- 当前代码按 6 位写好，如果你实际上只有 4 位，我可以继续帮你改成 4 位版本
- 四个按键当前采用 `A0` 电阻分压读取，不适合多键同时按下

## 12. 可继续优化的方向

- 用 `74HC595 + 三极管` 再减少 Arduino 占用引脚

- 增加按键，在“时间 / 日期 / 温度 / 湿度”之间手动切换
- 增加亮度控制，例如夜间自动变暗
