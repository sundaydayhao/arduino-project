# Arduino Uno 六位数码管时钟

这个版本改成了 **全数字 IO + 2 个 74HC595** 的方案。

目标有两个：

- 6 个独立数码管继续保留动态扫描显示
- 不再使用 `A0~A5` 和模拟按键分压，全部改成独立数字口

当前代码固定按 **6 个 18101BS 共阳数码管** 编写，显示内容如下：

- 时间：`HH.MM.SS`
- 日期：`YY.MM.DD`
- 温度：`t23.5C`
- 湿度：`h56.2H`

代码文件见：[uno_6digit_clock.ino](./uno_6digit_clock.ino)

## 1. 方案概览

新的接线思路：

- 用 **2 个 74HC595 串联**
- 第 1 个 `74HC595` 负责 `a b c d e f g dp`
- 第 2 个 `74HC595` 负责 6 位位选
- 位选仍然通过 `BC327` 控制每一位数码管公共阳极
- 4 个按键改成 4 根独立数字输入，并使用 `INPUT_PULLUP`
- `DS1302` 和 `DHT11` 也都改接数字口

这样 Arduino Uno 只需要这些数字口：

- `D2 D3 D4`：2 个 `74HC595`
- `D5 D6 D7`：`DS1302`
- `D8`：`DHT`
- `D9 D10 D11 D12`：4 个按键

因此：

- 不再占用 `A0~A5`
- `D0/D1` 仍可保留给串口
- `D13` 也空出来了

## 2. 器件清单

- Arduino Uno 1 块
- 独立一位七段数码管 6 个
- `74HC595` 2 片
- `BC327` PNP 三极管 6 个
- `330R` 电阻 8 个
  每个段线一只，`a b c d e f g dp` 各 1 个
- `1k` 电阻 6 个
  每个 `BC327` 基极串一只
- `10k` 电阻 6 个
  每个 `BC327` 基极上拉一只
- DS1302 RTC 芯片 1 颗
- DIP-8 底座或转接板 1 个
- 32.768kHz 时钟晶振 1 个
- DHT11 模块 1 个
- `10k` 电阻 1 个
  给 DHT 数据线做上拉
- 轻触按键 4 个
- 0.1uF 去耦电容若干
  建议每片 `74HC595` 和 `DS1302` 附近都放 1 个
- CR2032 纽扣电池 1 个
  可选，用于 `DS1302` 掉电保持
- 面包板、导线若干

## 3. 引脚分配

### 74HC595

- `D2` -> `SER/DS`
- `D3` -> `SRCLK/SHCP`
- `D4` -> `RCLK/STCP`

### DS1302

- `D5` -> `CE/RST`
- `D6` -> `I/O`
- `D7` -> `SCLK`

### DHT11

- `D8` -> `DATA`

### 四个按键

- `D9` -> `功能`
- `D10` -> `选择`
- `D11` -> `数值加`
- `D12` -> `数值减`

代码使用 `INPUT_PULLUP`，所以按键接法是：

- 按键一端接对应数字口
- 按键另一端直接接 `GND`

空闲时读到 `HIGH`，按下时读到 `LOW`。

## 4. 74HC595 接线

使用 **两个 74HC595 串联**。

串联顺序固定为：

- Arduino -> 第 1 个 `74HC595` -> 第 2 个 `74HC595`
- 第 1 个负责段线
- 第 2 个负责位选

公共连接：

- 两片 `74HC595` 的 `SRCLK` 并在一起，接 `D3`
- 两片 `74HC595` 的 `RCLK` 并在一起，接 `D4`
- 第 1 片 `SER` 接 `D2`
- 第 1 片 `Q7'` 接第 2 片 `SER`
- 两片 `OE` 直接接 `GND`
- 两片 `MR` 直接接 `5V`
- 两片 `VCC` 接 `5V`
- 两片 `GND` 接 `GND`

建议每片 `74HC595` 的 `VCC` 和 `GND` 之间各并一个 `0.1uF` 去耦电容。

### 第 1 个 74HC595：段线输出

`Q0~Q7` 对应关系：

- `Q0` -> `a`
- `Q1` -> `b`
- `Q2` -> `c`
- `Q3` -> `d`
- `Q4` -> `e`
- `Q5` -> `f`
- `Q6` -> `g`
- `Q7` -> `dp`

每一路都要先串一个 `330R` 电阻，再并到 6 个数码管对应段脚上。

### 第 2 个 74HC595：位选输出

`Q0~Q5` 对应 6 位数码管：

- `Q0` -> 第 1 位
- `Q1` -> 第 2 位
- `Q2` -> 第 3 位
- `Q3` -> 第 4 位
- `Q4` -> 第 5 位
- `Q5` -> 第 6 位

`Q6` 和 `Q7` 当前不用，可以悬空不接。

## 5. 数码管位选接法

数码管仍然按 **共阳动态扫描** 工作。

每个 `BC327` 连接方式：

- 发射极 `E` -> `5V`
- 集电极 `C` -> 对应那一位数码管公共阳极
- 基极 `B` -> 通过 `1k` 电阻接到第 2 个 `74HC595` 的对应 `Qx`
- 基极 `B` -> 再通过 `10k` 电阻上拉到 `5V`

6 位从左到右建议固定为：

- 第 1 位：小时十位 / 年十位
- 第 2 位：小时个位 / 年个位
- 第 3 位：分钟十位 / 月十位
- 第 4 位：分钟个位 / 月个位
- 第 5 位：秒钟十位 / 日十位 / 单位字符
- 第 6 位：秒钟个位 / 日个位

位选逻辑：

- 对共阳位选来说，`BC327` 基极拉低时，该位导通
- 所以代码里第 2 个 `74HC595` 的位选输出是 **低电平有效**

段线逻辑：

- 共阳数码管点亮某一段时，段线需要输出 `LOW`
- 所以第 1 个 `74HC595` 的段线输出也是 **低电平有效**

## 6. RTC 和传感器接线

### DS1302

- `CE/RST` -> `D5`
- `I/O` -> `D6`
- `SCLK` -> `D7`
- `VCC2` -> `5V`
- `GND` -> `GND`
- `VCC1` -> 纽扣电池正极
- 纽扣电池负极 -> `GND`
- `X1` 与 `X2` 之间接一个 `32.768kHz` 晶振

补充：

- `DS1302` 不是 I2C
- 不需要 `SDA/SCL` 上拉
- 不用 `Wire` 库
- 不建议开启涓流充电去充普通 `CR2032`

### DHT11

- `VCC` -> `5V`
- `GND` -> `GND`
- `DATA` -> `D8`
- `DATA` 与 `5V` 之间接 `10k` 上拉

## 7. 按键接线

当前代码不再使用电阻分压。

4 个按键全部按下面方式接：

- `D9` 连接 `功能` 键，按下接地
- `D10` 连接 `选择` 键，按下接地
- `D11` 连接 `数值加` 键，按下接地
- `D12` 连接 `数值减` 键，按下接地

由于代码启用了 `INPUT_PULLUP`：

- 空闲时输入为 `HIGH`
- 按下时输入为 `LOW`
- 不需要额外上拉电阻

## 9. 按键操作

默认交互逻辑如下：

- `功能` 短按：切换显示页面
- `选择` 短按：保持当前页面约 10 秒，不再自动轮播
- `选择` 长按：进入时间/日期设置模式
- `数值加` 短按：普通显示下切到上一页；设置模式下当前字段加 1
- `数值减` 短按：普通显示下切到下一页；设置模式下当前字段减 1

设置模式下：

- 当前字段会闪烁
- `选择` 短按：切换下一个字段
- `功能` 短按：保存并退出
- `功能` 长按：取消并退出
- 长按 `数值加/数值减` 会连续调整

设置字段顺序：

- `时`
- `分`
- `秒`
- `年`
- `月`
- `日`

## 10. 软件依赖

Arduino IDE 里通过库管理器安装：

- `DHT sensor library` by Adafruit

如果提示缺少 `Adafruit Unified Sensor`，一并安装。

## 11. 烧录步骤

1. 打开 [uno_6digit_clock.ino](./uno_6digit_clock.ino)
2. 当前代码默认使用 `DHT11`
3. 确认接线与本文档中的 `D2~D12` 分配一致
4. 编译并上传

第一次给 `DS1302` 上电，或者检测到 RTC 停止后，程序会自动把时间设置为 **编译时刻**。

如果你想手动写死一次时间，可以临时取消下面两行的注释，上传一次后再注释回去：

```cpp
// ClockTime fixed = {2026, 4, 6, 1, 12, 0, 0};
// writeRtc(fixed);
```

## 12. 显示逻辑

程序每隔几秒自动轮播：

- 时间：`12.34.56`
- 日期：`26.04.06`
- 温度：`t23.5C`
- 湿度：`h56.2H`

说明：

- 时间页第 2 位和第 4 位小数点闪烁，起到冒号效果
- 日期页第 2 位和第 4 位小数点常亮
- 温度和湿度页固定占满 6 位
- 温度和湿度页第 1 位用 `t` / `h` 标识

## 13. 调试建议

- 如果所有位都不亮，先检查两片 `74HC595` 的 `OE` 是否接地、`MR` 是否接 `5V`
- 如果位选乱跳，检查第 1 片 `Q7'` 到第 2 片 `SER` 的串联是否接对
- 如果某一段始终不亮，检查第 1 片 `74HC595` 对应 `Qx` 到段线的连接
- 如果某一位始终不亮，检查对应 `BC327`、`1k` 基极电阻、`10k` 上拉和公共阳极接线
- 如果时间不走，检查 `DS1302` 的 `CE/I/O/SCLK` 是否接到 `D5/D6/D7`
- 如果温湿度一直显示横杠，检查 `DHTTYPE` 是否保持为 `DHT11`，以及 `D8` 数据线上拉是否存在
- 如果按键无反应，先直接测 `D9~D12` 是否能在按下时被拉到 `LOW`

## 14. 重要限制

- 当前代码固定按 **6 个独立共阳数码管** 编写
- 当前代码固定按 **2 个 74HC595 串联** 编写
- 按键采用独立数字输入，不支持一根线多键分压

## 15. 可继续优化的方向

- 把位选部分从 `BC327` 换成更适合的高边驱动阵列
- 增加亮度控制，例如用 `OE` 做 PWM 调光
- 增加蜂鸣器或整点报时
- 如果后续还想继续省 IO，可以把按键也挂到扩展芯片
