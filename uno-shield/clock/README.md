# Arduino Uno 六位数码管时钟

这个版本改成了 **全数字 IO + 2 个 74HC595** 的方案。

目标有两个：

- 6 个独立数码管继续保留动态扫描显示
- 不再使用 `A0~A5` 和模拟按键分压，全部改成独立数字口

当前代码固定按 **6 个 18101BS 共阳数码管** 编写，显示内容如下：

- 时间：`HH.MM.SS`
- 日期：`YY.MM.DD`
- 温度：`t23.5C`
- 湿度：`h56.2H`

代码文件见：[uno_6digit_clock.ino](./uno_6digit_clock/uno_6digit_clock.ino)

## 1. 方案概览

新的接线思路：

- 用 **2 个 74HC595 串联**
- 第 1 个 `74HC595` 负责 `a b c d e f g dp`
- 第 2 个 `74HC595` 负责 6 位位选
- 位选仍然通过 `BC327` 控制每一位数码管公共阳极
- 4 个按键改成 4 根独立数字输入，并使用 `INPUT_PULLUP`
- `DS1302` 和 `DHT11` 也都改接数字口

这样 Arduino Uno 只需要这些数字口：

- `D2 D3 D4`：2 个 `74HC595`
- `D5 D6 D7`：`DS1302`
- `D8`：`DHT`
- `D9 D10 D11 D12`：4 个按键

因此：

- 不再占用 `A0~A5`
- `D0/D1` 仍可保留给串口
- `D13` 也空出来了

## 2. 器件清单

- Arduino Uno 1 块
- 独立一位七段数码管 6 个
- `74HC595` 2 片
- `BC327` PNP 三极管 6 个
- `330R` 电阻 8 个
  每个段线一只，`a b c d e f g dp` 各 1 个
- `1k` 电阻 6 个
  每个 `BC327` 基极串一只
- `10k` 电阻 6 个
  每个 `BC327` 基极上拉一只
- DS1302 RTC 芯片 1 颗
- DIP-8 底座或转接板 1 个
- 32.768kHz 时钟晶振 1 个
- DHT11 模块 1 个
- `10k` 电阻 1 个
  给 DHT 数据线做上拉
- 轻触按键 4 个
- 0.1uF 去耦电容若干
  建议每片 `74HC595` 和 `DS1302` 附近都放 1 个
- CR2032 纽扣电池 1 个
  可选，用于 `DS1302` 掉电保持
- 面包板、导线若干

## 3. 引脚分配

### 74HC595

- `D2` -> `SER`（有些资料也写作 `DS`）
- `D3` -> `SRCLK`（有些资料也写作 `SHCP`）
- `D4` -> `RCLK`（有些资料也写作 `STCP`）

### DS1302

- `D5` -> `CE/RST`
- `D6` -> `I/O`
- `D7` -> `SCLK`

### DHT11

- `D8` -> `DATA`

### 四个按键

- `D9` -> `功能`
- `D10` -> `选择`
- `D11` -> `数值加`
- `D12` -> `数值减`

代码使用 `INPUT_PULLUP`，所以按键接法是：

- 按键一端接对应数字口
- 按键另一端直接接 `GND`

空闲时读到 `HIGH`，按下时读到 `LOW`。

## 4. 74HC595 接线

使用 **两个 74HC595 串联**。

串联顺序固定为：

- Arduino -> 第 1 个 `74HC595` -> 第 2 个 `74HC595`
- 第 1 个负责段线
- 第 2 个负责位选

如果你用的是图里这种 `HG74HC595N / 74HC595` 的 DIP-16 符号，管脚名与管脚号对应如下：

- `16` -> `VCC`
- `8` -> `GND`
- `14` -> `SER`
- `11` -> `SRCLK`
- `12` -> `RCLK`
- `13` -> `OE#`
- `10` -> `SRCLR#`
- `9` -> `QH'`
- `15/1/2/3/4/5/6/7` -> `QA/QB/QC/QD/QE/QF/QG/QH`

公共连接：

- 两片 `74HC595` 的 `11脚 SRCLK` 并在一起，接 `D3`
- 两片 `74HC595` 的 `12脚 RCLK` 并在一起，接 `D4`
- 第 1 片 `14脚 SER` 接 `D2`
- 第 1 片 `9脚 QH'` 接第 2 片 `14脚 SER`
- 两片 `13脚 OE#` 直接接 `GND`
- 两片 `10脚 SRCLR#` 直接接 `5V`
- 两片 `16脚 VCC` 接 `5V`
- 两片 `8脚 GND` 接 `GND`

建议每片 `74HC595` 的 `VCC` 和 `GND` 之间各并一个 `0.1uF` 去耦电容。

### 第 1 个 74HC595：段线输出

按你图里的命名，`QA~QH` 对应关系如下：

- `QA`（15脚）-> `a`
- `QB`（1脚）-> `b`
- `QC`（2脚）-> `c`
- `QD`（3脚）-> `d`
- `QE`（4脚）-> `e`
- `QF`（5脚）-> `f`
- `QG`（6脚）-> `g`
- `QH`（7脚）-> `dp`

每一路都要先串一个 `330R` 电阻，再并到 6 个数码管对应段脚上。

### 第 2 个 74HC595：位选输出

第 2 片同样按 `QA~QH` 命名，其中前 6 路对应 6 位数码管：

- `QA`（15脚）-> 第 1 位
- `QB`（1脚） -> 第 2 位
- `QC`（2脚） -> 第 3 位
- `QD`（3脚） -> 第 4 位
- `QE`（4脚） -> 第 5 位
- `QF`（5脚） -> 第 6 位

- `QG`（6脚）和 `QH`（7脚）当前不用，可以悬空不接。

## 5. 数码管位选接法

数码管仍然按 **共阳动态扫描** 工作。

每个 `BC327` 连接方式：

- 发射极 `E` -> `5V`
- 集电极 `C` -> 对应那一位数码管公共阳极
- 基极 `B` -> 通过 `1k` 电阻接到第 2 个 `74HC595` 的对应 `QA~QF`
- 基极 `B` -> 再通过 `10k` 电阻上拉到 `5V`

6 位从左到右建议固定为：

- 第 1 位：小时十位 / 年十位
- 第 2 位：小时个位 / 年个位
- 第 3 位：分钟十位 / 月十位
- 第 4 位：分钟个位 / 月个位
- 第 5 位：秒钟十位 / 日十位 / 单位字符
- 第 6 位：秒钟个位 / 日个位

位选逻辑：

- 对共阳位选来说，`BC327` 基极拉低时，该位导通
- 所以代码里第 2 个 `74HC595` 的位选输出是 **低电平有效**

段线逻辑：

- 共阳数码管点亮某一段时，段线需要输出 `LOW`
- 所以第 1 个 `74HC595` 的段线输出也是 **低电平有效**

## 6. RTC 和传感器接线

### DS1302

- `CE/RST` -> `D5`
- `I/O` -> `D6`
- `SCLK` -> `D7`
- `VCC2` -> `5V`
- `GND` -> `GND`
- `VCC1` -> 纽扣电池正极
- 纽扣电池负极 -> `GND`
- `X1` 与 `X2` 之间接一个 `32.768kHz` 晶振

补充：

- `DS1302` 不是 I2C
- 不需要 `SDA/SCL` 上拉
- 不用 `Wire` 库
- 不建议开启涓流充电去充普通 `CR2032`

### DHT11

- `VCC` -> `5V`
- `GND` -> `GND`
- `DATA` -> `D8`
- `DATA` 与 `5V` 之间接 `10k` 上拉
- 上拉电阻不是串在 `D8` 和 `DATA` 中间；正确接法是 `D8` 与 `DATA` 直接相连，并从这个节点再接一只电阻到 `5V`

## 7. 按键接线

当前代码不再使用电阻分压。

4 个按键全部按下面方式接：

- `D9` 连接 `功能` 键，按下接地
- `D10` 连接 `选择` 键，按下接地
- `D11` 连接 `数值加` 键，按下接地
- `D12` 连接 `数值减` 键，按下接地

由于代码启用了 `INPUT_PULLUP`：

- 空闲时输入为 `HIGH`
- 按下时输入为 `LOW`
- 不需要额外上拉电阻

## 9. 按键操作

默认交互逻辑如下：

- `功能` 短按：切换显示页面
- `选择` 短按：保持当前页面约 10 秒，不再自动轮播
- `选择` 长按：进入时间/日期设置模式
- `数值加` 短按：普通显示下切到上一页；设置模式下当前字段加 1
- `数值减` 短按：普通显示下切到下一页；设置模式下当前字段减 1

设置模式下：

- 当前字段会闪烁
- `选择` 短按：切换下一个字段
- `功能` 短按：保存并退出
- `功能` 长按：取消并退出
- 长按 `数值加/数值减` 会连续调整

设置字段顺序：

- `时`
- `分`
- `秒`
- `年`
- `月`
- `日`

## 11. 烧录步骤

1. 打开 [uno_6digit_clock.ino](./uno_6digit_clock/uno_6digit_clock.ino)
2. 当前代码默认使用 `DHT11`
3. 确认接线与本文档中的 `D2~D12` 分配一致
4. 编译并上传
5. 如需调试，打开串口监视器，波特率设为 `115200`

第一次给 `DS1302` 上电、检测到 RTC 停止、或者 RTC 时间早于本次 sketch 的编译时间时，程序会自动把 RTC 设置为 **编译时刻**。
显示页面使用这个校准后的 RTC 时间作为实际时间；Arduino Uno 本身没有电脑系统时间，离线运行时需要靠 DS1302 持续走时。

推荐用串口监视器校时：

```text
TIME?
SET 2026-04-28 23:05:00
COMPILE
```

串口监视器波特率设为 `115200`，行尾选择 `Newline` 或 `Both NL & CR`。

说明：

- `TIME?`：读取当前 RTC 时间
- `SET 2026-04-28 23:05:00`：把 RTC 设置为指定时间
- `COMPILE`：把 RTC 设置为当前 sketch 的编译时间
- 如果 RTC 显示的是旧日期，重新编译上传后会自动校准到编译时间
- 程序会对 RTC 连续重读过滤；如果短时间内仍读坏，会用最近一次可信 RTC 时间按 `millis()` 临时续显，避免 DS1302 通信偶发误读时短暂显示 `rtc=halted` / `rtc=invalid`
- 如果只想上传时强制写一次编译时间，也可以临时把代码里的 `FORCE_RTC_SET_FROM_COMPILE_TIME_ON_BOOT` 改成 `true`，上传一次后再改回 `false`

## 12. 显示逻辑

程序默认按 `60` 秒周期低频切换：

- 时间：`12.34.56`，约 `45` 秒
- 日期：`26.04.06`，约 `5` 秒
- 温度：`t23.5C`，约 `5` 秒
- 湿度：`h56.2H`，约 `5` 秒

说明：

- 上电后会先逐位全段点亮约 1 秒，作为显示硬件自检
- 时间页第 2 位和第 4 位小数点常亮，起到冒号效果，避免每秒闪烁
- 日期页第 2 位和第 4 位小数点常亮
- 默认开启温湿度页，如果 DHT 未接好或读数失败，会短暂显示 `t----` / `h----`
- 如果只想显示时间和日期，把代码里的 `ENABLE_SENSOR_PAGES` 改成 `false`
- 要调整每页时长，修改 `AUTO_DATE_DISPLAY_MS`、`AUTO_TEMP_DISPLAY_MS`、`AUTO_HUMI_DISPLAY_MS`
- DHT 默认每 `10` 秒读取一次，避免过于频繁读取影响显示刷新
- 温度和湿度页固定占满 6 位
- 温度和湿度页第 1 位用 `t` / `h` 标识

## 13. 调试建议

- 代码默认开启 `ENABLE_SERIAL_DEBUG`，串口会打印启动配置、RTC 状态、页面变化、按键事件和 DHT 读数；默认不按每秒时间变化打印，避免串口阻塞导致显示闪烁
- 如果上电自检阶段也完全不亮，问题基本不在 `DS1302` / `DHT11`，先查显示驱动链路
- 如果所有位都不亮，先检查两片 `74HC595` 的 `13脚 OE#` 是否接地、`10脚 SRCLR#` 是否接 `5V`
- 如果所有位都不亮或位选乱跳，检查第 1 片 `9脚 QH'` 到第 2 片 `14脚 SER` 的串联是否接对；第 2 片 `14脚 SER` 不能悬空
- 如果某一段始终不亮，检查第 1 片 `74HC595` 对应 `QA~QH` 到段线的连接
- 如果某一位始终不亮，检查对应 `BC327`、`1k` 基极电阻、`10k` 上拉和公共阳极接线
- 如果 595 输出和位选都有动作但仍不亮，确认实际装上的数码管是共阳型号；共阴数码管不能配这套 `BC327` 高边位选接法
- 如果时间不走，检查 `DS1302` 的 `CE/I/O/SCLK` 是否接到 `D5/D6/D7`
- 如果温湿度一直显示横杠，检查 `DHTTYPE` 是否保持为 `DHT11`，以及 `D8` 数据线上拉是否存在
- 如果按键无反应，先直接测 `D9~D12` 是否能在按下时被拉到 `LOW`

## 14. 重要限制

- 当前代码固定按 **6 个独立共阳数码管** 编写
- 当前代码固定按 **2 个 74HC595 串联** 编写
- 按键采用独立数字输入，不支持一根线多键分压

## 15. 可继续优化的方向

- 把位选部分从 `BC327` 换成更适合的高边驱动阵列
- 增加亮度控制，例如用 `OE#` 做 PWM 调光
- 增加蜂鸣器或整点报时
- 如果后续还想继续省 IO，可以把按键也挂到扩展芯片
