# Arduino Uno 独立数码管时钟/温湿度显示

这个方案不使用 TM1637 模块，直接用多个**独立一位数码管**做动态扫描显示。你现在使用的是 **18101BS 共阳型数码管**，所以下面的硬件说明已经按**共阳动态扫描**整理。推荐做成 **6 位数码管**，这样能完整显示：

- 时间：`HH.MM.SS`
- 日期：`YY.MM.DD`
- 温度：`t23.5C`
- 湿度：`h56.2H`

代码文件见：[uno_6digit_clock.ino](D:\workspace\arduino-project\uno-shield\clock\uno_6digit_clock.ino)

## 1. 器件清单

- Arduino Uno 1 块
- 独立一位七段数码管 6 个
- DS3231 RTC 时钟模块 1 个
- DHT11 或 DHT22 温湿度模块 1 个
- PNP 三极管 6 个
  推荐 `S8550`、`SS8550`、`2N2907`
- 330 欧电阻 8 个
  每个段线一只，`a b c d e f g dp` 各 1 个
- 1k 欧电阻 6 个
  每个三极管基极一只
- 10k 欧电阻 1 个
  给 DHT 数据线做上拉，如果你用的是带板载电阻的模块可以省掉
- 面包板、导线若干

## 2. 显示器连接方式

默认按 **18101BS 共阳极数码管** 说明，且使用**动态扫描**。

核心思路：

- 6 个数码管的 `a` 段全部并在一起
- 6 个数码管的 `b` 段全部并在一起
- 其余 `c d e f g dp` 也分别并在一起
- 每一组段线只接一个限流电阻
- 每个数码管的公共阳极单独接一个 PNP 三极管做位选
- 程序快速轮流点亮 6 位，人眼看起来就是同时亮

共阳动态扫描的工作方式：

- 某一位被选中时，它的公共阳极被接到 `5V`
- 需要点亮的段线由 Arduino 输出 `LOW` 导通
- 不需要点亮的段线输出 `HIGH`

## 3. Arduino 引脚分配

### 段线

- `D2` -> `a`
- `D3` -> `b`
- `D4` -> `c`
- `D5` -> `d`
- `D6` -> `e`
- `D7` -> `f`
- `D8` -> `g`
- `D9` -> `dp`

每一条段线都要串一个 `330R` 电阻。

### 位选

- 第 1 位公共阳极 -> 三极管 1 集电极，基极控制脚 `D10`
- 第 2 位公共阳极 -> 三极管 2 集电极，基极控制脚 `D11`
- 第 3 位公共阳极 -> 三极管 3 集电极，基极控制脚 `D12`
- 第 4 位公共阳极 -> 三极管 4 集电极，基极控制脚 `D13`
- 第 5 位公共阳极 -> 三极管 5 集电极，基极控制脚 `A0`
- 第 6 位公共阳极 -> 三极管 6 集电极，基极控制脚 `A1`

每个 PNP 三极管连接方式：

- 发射极 -> `5V`
- 集电极 -> 对应那一位数码管的公共阳极
- 基极 -> 通过 `1k` 电阻接到 Arduino 位选引脚

位选逻辑：

- Arduino 位选脚输出 `LOW` -> 对应数码管这一位导通
- Arduino 位选脚输出 `HIGH` -> 对应数码管这一位关闭

## 4. RTC 和温湿度模块接线

### DS3231

- `VCC` -> `5V`
- `GND` -> `GND`
- `SDA` -> `A4`
- `SCL` -> `A5`

### DHT11 / DHT22

- `VCC` -> `5V`
- `GND` -> `GND`
- `DATA` -> `A2`
- `DATA` 与 `5V` 之间接 `10k` 上拉

## 6. 软件依赖

Arduino IDE 里通过库管理器安装：

- `RTClib` by Adafruit
- `DHT sensor library` by Adafruit

如果 Arduino IDE 提示缺少 `Adafruit Unified Sensor`，一并安装。

## 7. 烧录步骤

1. 打开 [uno_6digit_clock.ino](D:\workspace\arduino-project\uno-shield\clock\uno_6digit_clock.ino)
2. 在代码顶部确认你使用的是 `DHT11` 还是 `DHT22`
3. 当前代码已经默认按 `18101BS` 共阳极配置，通常不用再改 `COMMON_ANODE`
4. 安装好依赖库后编译并上传

第一次给 DS3231 上电或者 RTC 掉电后，程序会自动把 RTC 时间设置为**编译时刻**。

如果你想手动写死一次时间，可以取消下面这一行的注释，上传一次后再注释回去：

```cpp

```

## 8. 显示逻辑

程序每隔几秒自动轮播：

- 时间：`12.34.56`
- 日期：`26.04.06`
- 温度：`t23.5C`
- 湿度：`h56.2H`

说明：

- 时间页中间的小数点会闪烁，起到冒号效果
- 日期页用两个小数点分隔年、月、日
- 温度和湿度页左边用 `t` / `h` 标识

## 9. 调试建议

- 如果所有段都乱亮，优先检查位选三极管是否真的是 **PNP**，以及公共端是否接到**公共阳极**
- 如果只有一位亮，检查对应位选三极管接法
- 如果段显示顺序错了，确认 `a~g, dp` 的引脚是否接对
- 如果温湿度一直是横杠，检查 DHT 类型是否设置正确，以及数据线上拉是否存在
- 如果时间不走，检查 DS3231 的 `SDA/SCL` 是否接到 `A4/A5`

## 10. 重要限制

- 这个方案默认你有 **6 个独立一位共阳数码管**
- 如果你只有 **4 位**，也能做，但显示策略要改成分页显示，例如只显示 `HHMM`、`MMDD`、`23.5`
- 当前代码按 6 位写好，如果你实际上只有 4 位，我可以继续帮你改成 4 位版本

## 11. 可继续优化的方向

- 用 `74HC595 + 三极管` 再减少 Arduino 占用引脚
- 用 `MAX7219` 驱动独立数码管，亮度和布线会更轻松
- 增加按键，在“时间 / 日期 / 温度 / 湿度”之间手动切换
- 增加亮度控制，例如夜间自动变暗
