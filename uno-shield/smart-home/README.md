# Smart Home Shield（智能家居中控 Shield）

基于 Arduino UNO R3 的智能家居原型控制器，集成温湿度、人体感应、光照检测、继电器控制、蜂鸣器报警和 OLED 实时显示。

---

## 📁 项目结构

```
shield/smart-home/
├── src/
│   └── smart_home.ino    # Arduino 主程序
└── README.md
```

## ✨ 功能概览

| 功能 | 说明 |
|------|------|
| 🌡️ 温湿度监测 | DHT11，每 3 秒读取，OLED 实时显示 |
| 👁️ 人体感应 | PIR 传感器，中断驱动，10 秒超时自动清除 |
| 💡 光照检测 | LDR 光敏电阻，ADC 读取 |

| 🔔 蜂鸣器报警 | AWAY 模式：检测到人 → 持续报警 |
| 📺 OLED 显示 | 128×64，显示温湿度/光照/人体/继电器状态/模式 |
| 📡 串口控制 | 切换模式、手动控制继电器、调整阈值 |

## 🔌 接线说明

### DHT11 温湿度传感器

| DHT11 引脚 | Arduino 引脚 | 说明 |
|-----------|-------------|------|
| VCC | 5V | 电源 |
| GND | GND | 地 |
| DATA | **Pin 4** | 数据，串联 10kΩ 上拉到 VCC |

### PIR 人体感应模块（HC-SR501）

| PIR 引脚 | Arduino 引脚 | 说明 |
|---------|-------------|------|
| VCC | 5V | 电源（部分模块需要 5–12V） |
| GND | GND | 地 |
| OUT | **Pin 2** | 输出，高电平有效，触发 INT0 中断 |

> 💡 HC-SR501 背面有两个电位器：
> - **Sx**：灵敏度调节（顺时针=更灵敏）
> - **Tx**：延时调节（顺时针=延时更长，建议调到最短约 3 秒）

### LDR 光敏电阻（分压电路）

```
5V ──┤ LDR ├──┬── A0（读取电压）
              │
             10kΩ
              │
             GND
```

> 光线越暗，A0 读数越小（LDR 阻值增大，分压点电压降低）

### 继电器模块

| 继电器 | Arduino 引脚 | 控制对象 | 触发方式 |
|-------|-------------|---------|---------|
| 继电器 1 | **Pin 7** | 灯光 | 低电平触发（LOW = ON） |
| 继电器 2 | **Pin 8** | 风扇/电器 | 低电平触发（LOW = ON） |

> ⚠️ 继电器模块通常为**低电平触发**（IN 接 LOW 时继电器吸合）。如果你的模块是高电平触发，修改代码中的 `RELAY_ON` 和 `RELAY_OFF` 定义：
> ```cpp
> #define RELAY_ON   HIGH   // 高电平触发
> #define RELAY_OFF  LOW
> ```

### 蜂鸣器

| 元件 | Arduino 引脚 | 说明 |
|------|-------------|------|
| 无源蜂鸣器 + | **Pin 9** | 另一端接 GND |

### OLED SSD1306（I2C）

| OLED 引脚 | Arduino 引脚 | 说明 |
|----------|-------------|------|
| VCC | 3.3V 或 5V | 电源 |
| GND | GND | 地 |
| SDA | **A4** | I2C 数据 |
| SCL | **A5** | I2C 时钟 |

## 🎮 三种工作模式

### AUTO 模式（默认）
自动根据传感器数据控制继电器：

| 条件 | 动作 |
|------|------|
| 光照 ADC < 阈值（暗）**且** 检测到人 | 继电器1（灯）→ ON |
| 光照 ADC ≥ 阈值（亮）**或** 无人 | 继电器1（灯）→ OFF |
| 温度 ≥ 阈值（默认 28°C） | 继电器2（风扇）→ ON |
| 温度 < 阈值 | 继电器2（风扇）→ OFF |

### MANUAL 模式
继电器完全由串口命令手动控制，传感器数据仍然采集和显示。

### AWAY 模式（离家）
- 继电器保持当前状态
- 检测到人体 → 蜂鸣器持续报警（500ms 间隔）
- 串口发送 `A` 可静音报警

## 🚀 使用步骤

1. **安装库**（见上方）
2. **按接线表连接硬件**
3. **上传代码**：`src/smart_home.ino`
4. **打开串口监视器**（波特率 9600）
5. **调节 PIR 模块**：将延时电位器调到最短（约 3 秒）
6. **调节光照阈值**：在正常室内光线下读取 A0 值（串口发送 `S`），将阈值设为该值的 80%

## 🔍 常见问题

### DHT11 读取失败（显示 N/A）
- 检查 DATA 引脚是否串联了 10kΩ 上拉电阻到 VCC
- DHT11 读取间隔不能小于 1 秒，代码已设置 3 秒
- 确认 Pin 4 接线正确

### PIR 一直触发 / 不触发
- 调节 HC-SR501 背面的灵敏度电位器
- 将延时电位器调到最短（逆时针到底）
- PIR 需要 30–60 秒预热时间，上电后等待再测试
- 确认 PIR 输出为高电平有效（大多数模块如此）

### 继电器不动作
- 检查 `RELAY_ON` 定义是否与模块匹配（低电平触发 = `LOW`）
- 确认继电器模块 VCC 接 5V，GND 接 GND
- 用万用表测量 Pin 7/8 输出电平

### OLED 无显示
- 检查 I2C 地址：默认 `0x3C`，部分模块为 `0x3D`
- 确认 SDA→A4，SCL→A5

### 蜂鸣器无声
- 确认使用**无源蜂鸣器**（passive buzzer）
- 检查 Pin 9 接线

## 💡 扩展建议

| 扩展方向 | 建议方案 |
|---------|---------|
| 远程控制 | 添加 ESP8266 WiFi 模块（Pin 10/11 SoftwareSerial） |
| 更多传感器 | MQ-2 气体传感器（A1）、雨滴传感器（A2） |
| 更精准温湿度 | 将 DHT11 替换为 DHT22（代码中改 `DHT_TYPE DHT22`） |
| 数据记录 | 添加 DS3231 RTC + SD 卡模块（I2C + SPI） |
| 语音控制 | 添加 LD3320 语音识别模块（UART） |
