# Sensor Hub Shield

多传感器数据采集扩展板，集成温湿度、光照、声音、双电位器、多按键、RGB LED、单色 LED 阵列与无源蜂鸣器，适合 Arduino 教学演示与原型验证。

---

## 硬件配置

| 元件 | 型号 / 规格 | Arduino 引脚 |
|------|------------|-------------|
| 温湿度传感器 | DHT22 | Pin 4 |
| 光敏电阻 | LDR + 10kΩ下拉 | A0 |
| 声音传感器 | 模拟输出模块 | A1 |
| 电位器 1 | 10kΩ（RGB色相） | A2 |
| 电位器 2 | 10kΩ（速度/亮度） | A3 |
| 按键 1 | 轻触开关（内部上拉） | Pin 2 (INT0) |
| 按键 2 | 轻触开关（内部上拉） | Pin 3 (INT1) |
| 按键 3 | 轻触开关（内部上拉） | Pin 7 |
| LED 红 | 5mm 红色 + 220Ω | Pin 13 |
| LED 黄 | 5mm 黄色 + 220Ω | Pin 12 |
| LED 绿 | 5mm 绿色 + 220Ω | Pin 11 |
| LED 蓝 | 5mm 蓝色 + 220Ω | Pin 10 |
| RGB LED | 共阴极 + 3×220Ω | R=Pin9 / G=Pin6 / B=Pin5 |
| 无源蜂鸣器 | 5V 无源 | Pin 8 |
| I2C 扩展接口 | — | A4(SDA) / A5(SCL) |

> **注意**：按键接线为一端接引脚、另一端接 GND，代码使用 `INPUT_PULLUP`，按下时为 LOW。

## 功能说明

### 传感器自动采集
每 **2 秒**通过串口（9600 baud）打印一次所有传感器数据：

```
─────────────────────────────
[DHT22] 温度: 25.3 °C  湿度: 58.2 %
[LDR  ] 光照: 612  (59%)
[声音 ] 强度: 234
[POT1 ] 色相: 180°
[POT2 ] 速度: 73
─────────────────────────────
```

### 按键功能

| 按键 | 功能 |
|------|------|
| **按键1**（Pin 2） | 循环切换 LED 演示模式：关闭 → 追逐 → 呼吸 → 全亮 |
| **按键2**（Pin 3） | 播放 / 停止蜂鸣器旋律（小星星，非阻塞） |
| **按键3**（Pin 7） | 切换 LDR 自动光控（光线越暗绿色 LED 越亮） |

### LED 演示模式

| 模式 | 效果 | POT2 作用 |
|------|------|-----------|
| **关闭** | 所有单色 LED 熄灭 | — |
| **追逐** | 红→黄→绿→蓝依次点亮 | 调节追逐速度（80ms–500ms） |
| **呼吸** | 蓝色 LED + RGB 蓝通道渐亮渐暗 | 调节呼吸速率 |
| **全亮** | 四色 LED 全部点亮 | — |

### RGB LED 色彩控制
- **POT1**：调节色相（0°–359°，全色轮）
- **POT2**：调节亮度（10–255）
- 内部使用 HSV → RGB 转换，颜色过渡平滑

### 串口命令

| 命令 | 功能 |
|------|------|
| `S` | 立即打印传感器数据 |
| `M` | 切换 LED 演示模式（同按键1） |
| `H` | 显示帮助信息 |

## 快速上手

1. 按照引脚分配图连接硬件
2. 在 Arduino IDE 中安装依赖库
3. 打开 `src/sensor_hub.ino` 并上传到 Arduino UNO
4. 打开串口监视器（9600 baud），观察传感器数据输出
5. 按下按键1 切换 LED 模式，旋转电位器调节 RGB 颜色

---

## 扩展建议

- 通过 I2C 接口（A4/A5）连接 **OLED SSD1306** 显示传感器数据
- 连接 **DS3231 RTC** 模块，为数据加上时间戳
- 将声音传感器数据用于声控 LED 效果（VU 表）
- 通过 HC-05 蓝牙模块将数据发送到手机 App

## 注意事项

- DHT22 上电后需等待约 **1 秒**才能正常读取，首次数据可能显示失败属正常现象
- 无源蜂鸣器使用 `tone()` 函数驱动，与 `analogWrite()` 共用定时器，在呼吸灯模式下蜂鸣器音调可能略有偏差
- VS Code 中 `DHT.h` 显示红色波浪线为 IntelliSense 路径未配置，**不影响 Arduino IDE 编译**
