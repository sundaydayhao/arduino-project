# LCD12864 图形时钟 Shield

基于 Arduino UNO R3 的图形时钟，使用 DS3231 RTC 模块实现高精度计时，LCD12864（ST7920 控制器）显示模拟时钟表盘 + 数字时间/日期/温度。

---

## 📁 项目结构

```
shield/lcd12864/
├── src/
│   └── lcd12864_clock.ino          # Arduino 主程序
├── schematic/
│   └── lcd12864_schematic.json     # 嘉立创EDA 原理图（可直接导入）
└── README.md                       # 本文档
```

```
┌────────────────────────────────┐

│    ╱  │  ╲      2024-03-25     │
│   │   ●   │    Mon             │

│      ╲  ╱                      │
└────────────────────────────────┘
  左：模拟时钟表盘    右：数字信息
```

## 🔌 接线说明

### LCD12864（ST7920，软件SPI模式）

> ⚠️ **关键**：`PSB` 引脚必须接 **GND**，才能启用 SPI 通信模式！

| LCD12864 引脚 | Arduino 引脚 | 说明 |
|--------------|-------------|------|
| VSS | GND | 电源地 |
| VDD | 5V | 电源正极 |
| V0 | 电位器中间脚 | 对比度调节（0–5V） |
| RS (CS) | **D10** | SPI 片选 |
| RW (SID) | **D9** | SPI 数据（MOSI） |
| E (SCLK) | **D8** | SPI 时钟 |
| PSB | **GND** | ← 必须接GND！ |
| RST | **D7** | 复位（可选，接5V也可） |
| BLA | 5V | 背光正极 |
| BLK | GND | 背光负极 |

### DS3231 RTC（I2C）

| DS3231 引脚 | Arduino 引脚 | 说明 |
|------------|-------------|------|
| VCC | 5V | 电源 |
| GND | GND | 地 |
| SDA | **A4** | I2C 数据 |
| SCL | **A5** | I2C 时钟 |

### 对比度电位器

```
5V ──┤1
     ├2 ──→ LCD V0
GND ─┤3
```

## 🚀 使用步骤

### 1. 安装库
```
Arduino IDE → 工具 → 管理库
搜索 "U8g2"    → 安装（by olikraus）
搜索 "RTClib"  → 安装（by Adafruit）
```

### 2. 上传代码
1. 打开 `src/lcd12864_clock.ino`
2. 选择开发板：`工具 → 开发板 → Arduino UNO`
3. 选择端口：`工具 → 端口 → 对应COM口`
4. 点击上传

### 3. 调节对比度
上传后如果屏幕无显示或显示全黑，旋转电位器调节对比度直到图像清晰。

### 4. 串口校时
打开串口监视器（波特率 **9600**）：

```
R                          ← 读取当前时间
T2024-03-25 12:30:00       ← 设置时间（格式：TYYYY-MM-DD HH:MM:SS）
```

## 🔍 常见问题

### LCD 无显示
- 检查 `PSB` 是否接 GND（最常见问题）
- 调节对比度电位器
- 确认 D8/D9/D10/D7 接线正确

### 显示乱码或花屏
- 检查 SPI 接线顺序（SCLK/SID/CS 不能接错）
- 确认 U8g2 初始化使用 `U8G2_ST7920_128X64_F_SW_SPI`

### 时间不准
- DS3231 精度极高，通常不会不准
- 通过串口 `T` 命令手动校时
- 检查 CR2032 电池是否安装

### RTC 初始化失败
- 检查 SDA→A4，SCL→A5 接线
- 确认 DS3231 模块 5V 供电正常
